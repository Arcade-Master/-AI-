## 题面

**不平衡数**：十进制表示中，**奇数位数字个数 ≠ 偶数位数字个数**（0 算偶数位）。

给定数字串 \(s\)（\(0\sim9\)），求其子序列中能组成**合法整数**且为不平衡数的个数，对 \(10^9+7\) 取模。

**合法整数（无 leading zero）**：

- 长度为 1 的子序列：任意一位数字均可（含 `0`）；
- 长度 \(\ge 2\)：首位必须是 `1..9`（不能以前导 0 开头）。

**子序列**：按原顺序删若干位，不改变相对次序。

---

## 思路

### 1. 答案 = 合法总数 − 平衡数个数

**合法总数**（无 leading zero 的数字子序列个数）：

- 每位 `0` 单独作为长度 1 的数：贡献 1；
- 每位非 `0` 的 `s[i]` 作为首位，后面 \(i+1..n-1\) 任意选或不选：贡献 \(2^{n-1-i}\)。

\[
\text{total} = \sum_{s[i]=0} 1 + \sum_{s[i]\ne 0} 2^{n-1-i}
\]

**单数字** 只有 1 位，奇偶个数不可能相等，故**全是不平衡**；只需从总长里减去**长度 \(\ge 2\) 且平衡**的子序列。

### 2. 平衡数 DP（按位选 / 不选）

维护 `diff = (#奇数位 - #偶数位)`，只统计**首位为非 0** 的子序列（`g`）。

对每个字符 `c`（`d = +1` 奇 / `-1` 偶）：

1. **不选** `c`：`ng = g`（拷贝上一状态）；
2. **选** `c`：对所有旧状态 `g[diff]`，累加到 `ng[diff+d]`（在旧 `g` 上扩展，不能把旧状态「挪走」）；
3. **新开**一位：若 `c != '0'`，`ng[d] += 1`（仅当前位的长度 1 子序列）。

要点：若只做「把旧状态迁到 diff+d」而不保留「不选当前位」的副本，会像 `122` 里第二个 `2` 无法再接到单独的 `1` 上，少算 `"12"`。

扫完后 `g[0]` = **平衡**且首位非 0 的子序列数（长度 1 的 diff≠0，不会进 `g[0]`）。

### 3. 最终

\[
\text{ans} = (\text{total} - f1[0]) \bmod (10^9+7)
\]

**复杂度**：\(O(n \cdot W)\)，\(W=O(n)\) 为 diff 范围，\(n\) 较大时可压成滚动数组；一般题设 \(n\le 10^5\) 需确认是否需优化——若 \(n\le 2000\) 直接数组即可。

**易错点**：

- 把「子序列」当成连续子串。
- 忘记单字符 `0` 是不平衡的。
- 模运算减法要 `+ MOD`。

## 参考实现

```python
import sys

MOD = 10**9 + 7


def parity_delta(ch: str) -> int:
    return 1 if int(ch) & 1 else -1


def count_balanced_multidigit(s: str) -> int:
    """首位非0、奇偶位个数相等的子序列数（含长度>=2）。"""
    n = len(s)
    off = n + 2
    size = 2 * off + 1
    g = [0] * size
    for ch in s:
        ng = g[:]
        d = parity_delta(ch)
        for diff in range(-n, n + 1):
            cnt = g[diff + off]
            if cnt:
                ng[diff + d + off] = (ng[diff + d + off] + cnt) % MOD
        if ch != "0":
            ng[d + off] = (ng[d + off] + 1) % MOD
        g = ng
    return g[off]


def total_valid(s: str) -> int:
    n = len(s)
    ans = 0
    for i, ch in enumerate(s):
        if ch == "0":
            ans += 1
        else:
            ans = (ans + pow(2, n - 1 - i, MOD)) % MOD
    return ans


def solve(s: str) -> int:
    bal = count_balanced_multidigit(s)
    return (total_valid(s) - bal) % MOD


def main() -> None:
    s = sys.stdin.readline().strip()
    if not s:
        return
    print(solve(s))


if __name__ == "__main__":
    main()
```

## 变体 / 追问

- 若 \(n\) 很大，diff 维度用 map 只存非零状态，或数学推导生成函数。
- 题面提示模逆元：组合数除法时用 `pow(q, MOD-2, MOD)`。

## 面试怎么答（30 秒）

「单数字一定不平衡。总数：每个非零位作首位带 \(2^{后缀}\) 种，每个 0 单独算 1。再 DP 减平衡：只维护首位已为非 0 的子序列，状态是奇数位减偶数位 diff，最后 diff=0 的是平衡。答案 total 减 balanced。」
