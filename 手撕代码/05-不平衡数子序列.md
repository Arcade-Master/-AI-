## 题面

**不平衡数**：十进制表示中，**奇数位数字个数 != 偶数位数字个数**（0 算偶数位）。

给定数字串 s（字符 0～9），求其子序列中能组成**合法整数**且为不平衡数的个数，对 **1e9+7** 取模。

**合法整数（无 leading zero）**：

- 长度为 1 的子序列：任意一位数字均可（含 `0`）；
- 长度 >= 2：首位必须是 1..9（不能以前导 0 开头）。

**子序列**：按原顺序删若干位，不改变相对次序（不要求连续）。

---

## 思路

### 1. 答案 = 合法总数 - 平衡数个数

**合法总数**（无 leading zero 的数字子序列个数）：

- 每位 `0` 单独作为长度 1 的数：贡献 1；
- 每位非 `0` 的 s[i] 作为首位，后面 i+1..n-1 任意选或不选：贡献 2^(n-1-i)。

```
total = (每个 0 贡献 1) + (每个非 0 位 i 贡献 2^(n-1-i))
```

**单数字**只有 1 位，奇偶个数不可能相等，故**全是不平衡**；只需从 total 里减去**首位非 0 且平衡**的子序列。

### 2. 平衡数 DP（按位选 / 不选）

维护 `diff = 奇数位个数 - 偶数位个数`，只统计**首位为非 0** 的子序列（数组 g）。

对每个字符 c（奇数位 +1，偶数位 -1）：

1. **不选** c：`ng = g`（拷贝上一状态）；
2. **选** c：对所有旧状态 g[diff]，累加到 ng[diff+d]（在旧 g 上扩展，不能把旧状态「挪走」）；
3. **新开**一位：若 c != '0'，ng[d] += 1（仅当前位单独成子序列）。

要点：若只做「把旧状态迁到 diff+d」而不保留「不选当前位」的副本，会像 `122` 里第二个 `2` 无法再接到单独的 `1` 上，少算 `12`。

扫完后 **g[0]** = 平衡且首位非 0 的子序列数（长度 1 的 diff 不为 0，不会进 g[0]）。

### 3. 最终

```
ans = (total - g[0]) % (1e9+7)
```

减法后若负，加 MOD。

**复杂度**：O(n * n) 状态维度（diff 范围 O(n)）；n 很大时可用 map 只存非零 diff。

**易错点**：

- 把「子序列」当成连续子串。
- 忘记单字符 `0` 是不平衡的。
- 模运算减法要 `+ MOD`。

## 参考实现

```python
MOD = 10**9 + 7


def parity_delta(ch: str) -> int:
    return 1 if int(ch) & 1 else -1


def count_balanced_multidigit(s: str) -> int:
    """首位非0、奇偶位个数相等的子序列数。"""
    n = len(s)
    off = n + 2
    size = 2 * off + 1
    g = [0] * size
    for ch in s:
        ng = g[:]
        d = parity_delta(ch)
        for diff in range(-n, n + 1):
            cnt = g[diff + off]
            if cnt:
                ng[diff + d + off] = (ng[diff + d + off] + cnt) % MOD
        if ch != "0":
            ng[d + off] = (ng[d + off] + 1) % MOD
        g = ng
    return g[off]


def total_valid(s: str) -> int:
    n = len(s)
    ans = 0
    for i, ch in enumerate(s):
        if ch == "0":
            ans += 1
        else:
            ans = (ans + pow(2, n - 1 - i, MOD)) % MOD
    return ans


def solve(s: str) -> int:
    bal = count_balanced_multidigit(s)
    return (total_valid(s) - bal) % MOD


def main() -> None:
    s = input().strip()
    print(solve(s))


if __name__ == "__main__":
    main()
```

---

## 变体 / 追问

- n 很大时 diff 用 map 压缩状态。
- 题面提示模逆元：组合数除法时用 `pow(q, MOD-2, MOD)`。

## 面试怎么答（30 秒）

「单数字一定不平衡。总数：每个非零位作首位带 2^后缀 种，每个 0 单独算 1。再 DP 减平衡：只维护首位已为非 0 的子序列，状态是奇数位减偶数位 diff，最后 diff=0 的是平衡。答案 total 减 balanced。」
