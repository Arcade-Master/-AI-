## 题面

**不平衡数**：十进制表示中，**奇数位数字个数 != 偶数位数字个数**（0 算偶数位）。

给定数字串 s（字符 0～9），求其子序列中能组成**合法整数**且为不平衡数的个数，对 **1e9+7** 取模。

**合法整数（无 leading zero）**：

- 长度为 1 的子序列：任意一位数字均可（含 `0`）；
- 长度 >= 2：首位必须是 1..9（不能以前导 0 开头）。

**子序列**：按原顺序删若干位，不改变相对次序（不要求连续）。

## 思路

**全文脉络（按这个顺序读，别先背变量）**：

```
最终答案 = 合法子序列总数 total  −  其中「平衡」的条数 balanced

§2  balanced 怎么数？ → 从左扫串、拼子序列，状态用 diff，这才要 DP

```

下面先讲完 §1，再讲 §2；**g、ng、d、off 全部放在 §2 搞懂思路之后**，用来对代码行号。

### 1. 第一步：数「合法」子序列 → total

#### 1.1 先弄清：什么叫「合法」子序列？

子序列 = 从下标里挑一些位置，**保持原顺序**，不要求连续。

题面规定：

| 长度 | 规则 |
|------|------|
| 1 | 任意一位单独成数都可以，含 `0` → 数就是 `0` |
| >= 2 | **第一位必须是 1～9**，不能出现前导 0 |

所以：

- `0` **只能**单独当一位数 `0`，不能当多位数的首位。
- `1..9` 既可以单独成一位，也可以当多位数的**首位**，后面再随便接后面的子序列。

计数时按 **「谁当首位」** 分类，保证不重不漏。

#### 1.2 为什么每个 `0` 只贡献 1？

下标 i 上是 `0` 时，合法方案只有一种：**只选 i 这一位**，得到数字 `0`。

不能选 `{i, j}` 且 j>i，那样首位是 0，违反「无前导 0」。

所以**每个 0 的下标** → 恰好 **1** 个合法子序列。

#### 1.3 为什么非 0 位 i 贡献 2^(n-1-i)？

下标 i 上是 `1..9` 时，可以当**多位数的首位**：

1. **必须选** i（首位定了就是 s[i]）；
2. 下标 **i+1, i+2, …, n-1** 一共 **(n-1-i)** 个位置，每个**独立**决定选或不选 → 各 2 种选择。

乘法原理：

```
2 * 2 * … * 2   （共 n-1-i 个）
= 2^(n-1-i)
```

其中也包括「后面一个都不选」→ 得到**只有一位**的数 s[i]（长度 1 的那一种也算在这一类里）。

#### 1.4 小例子：s = "122"（下标 0,1,2）

| 首位下标 | 字符 | 后面有几个位置 | 贡献 | 具体子序列（按选的下标） |
|----------|------|----------------|------|---------------------------|
| 0 | 1 | 2 个 (1,2) | 2^2 = 4 | 只选{0}→`1`；{0,1}→`12`；{0,2}→`12`；{0,1,2}→`122` |
| 1 | 2 | 1 个 (2) | 2^1 = 2 | {1}→`2`；{1,2}→`22` |
| 2 | 2 | 0 个 | 2^0 = 1 | {2}→`2` |

合计 **4+2+1 = 7** 个合法子序列（两个 `12` 下标不同，算两个）。

**没有 0** 时就不加「每个 0 贡献 1」那一项。

#### 1.5 公式汇总

```
total = (每个 0 下标 +1)
      + (每个非 0 下标 i，+ 2^(n-1-i))
```

**单数字**只有 1 位，奇偶个数不可能相等 → **单字符一定不平衡**。  
要从 total 里减掉的，只是：**至少两位、首位非 0、且奇偶位个数相等** 的那些（平衡的）。

### 2. 第二步：数「平衡的」→ 用 DP（先思路，变量放最后）

#### 2.1 这一步要数什么、为啥不能套 §1 的公式

要数的 **balanced**：

- 是 s 的一个子序列；
- 首位是 1～9（无前导 0）；
- **奇数位数字个数 == 偶数位数字个数**（0 算偶数位）。

子序列有 2^n 种，不能枚举。§1 的「固定首位 + 后面随便选」只适用于数 **total**，因为 total 不按奇偶分类；这里必须盯着 **奇偶是否打平**，所以要 **DP**。

#### 2.2 解题方向：从左到右扫，边扫边「造」子序列

想象从 s 的左边往右扫，当前看到字符 `ch`，手里已经造了一批 **合法的、首位非 0 的** 子序列（有的短、有的长）。

对 **每一个已经造好的子序列**，到 `ch` 这里只有两种选择：

- **不要** `ch` → 子序列不变；
- **要** `ch` → 接到末尾，多一位数字。

另外，如果 `ch` 自己是 1～9，还可以 **只选 ch 这一位**，新开一条长度为 1 的子序列。  
（`ch` 是 0 不能新开多位首位，只能接到已有子序列后面。）

**DP 要回答的问题**：扫完前 i 个字符后，「这类子序列」分别有多少条？

#### 2.3 为啥用 diff 当状态（数组下标为啥是 diff）——核心

扫到一半时，以后还能不能变「平衡」，只取决于一件事：

> 已经选进去的数里，**奇数位个数** 和 **偶数位个数** 各是多少。

不必记住具体选了哪几个下标（那是暴力枚举的事）。  
用一个数概括就够了：

```
diff = 奇数位个数 - 偶数位个数
```

- **平衡** ⟺ 奇数位个数 == 偶数位个数 ⟺ **diff == 0**
- 每在末尾接一个数字：
  - 接的是奇数 → 奇数位 +1 → **diff 加 1**
  - 接的是偶数（含 0）→ 偶数位 +1 → **diff 减 1**

所以：**所有「当前 diff 相同」的半成品子序列，在后面能怎么变、对最终计数有啥影响，是一类的。**  
DP 就按 diff 分组计数：

```
g[diff] = 扫完目前这些字符后，
          「首位已是 1～9」且「奇偶差 = diff」的子序列，一共有多少条
```

这就是 **为啥开数组、下标用 diff**：不是先拍脑袋要数组，而是 **状态只有 diff 这一维有用**。

`off` 只是实现：diff 可能是负数，Python 列表下标要非负，所以存成 `g[diff + off]`，**心里仍叫 diff**。

**off 取多少？** diff 最极端是「全选奇数位」或「全选偶数位」，最多 n 位，故 **diff 只在 -n～n**。映射 `下标 = diff + off` 时，**off = n 就够**（diff=-n→0，diff=n→2n，数组长度 `2n+1`）。  
代码里写 `off = n + 2` 只是多留两格边距，**不影响答案**，不是题意要求；下面参考实现改成 `off = n`，更贴推导。

#### 2.4 一轮扫描在干啥（仍不用背 ng、g 名字）

处理当前字符 `ch` 时，逻辑就三条：

| 操作 | 含义 | diff 怎么变 |
|------|------|-------------|
| 不选 ch | 旧子序列全部保留 | 不变 |
| 在旧子序列末尾接上 ch | 每条旧方案多一种接法 | 每条 diff 变成 diff+d（d 由 ch 奇偶定） |
| 只选 ch 单独成一位 | 新开一条（仅 ch 为 1～9） | 新子序列 diff = d |

其中 **d**：当前位 ch 带来的变化，奇数 d=+1，偶数 d=-1。

**为啥要先复制再更新（对应代码 `ng = g[:]`）**  
「不选 ch」和「选 ch 接到旧子序列上」要 **同时** 从 **同一批旧方案** 出发。  
若只把旧方案「搬家」到 diff+d、不保留原 diff，等于强制每个旧方案都接了 ch，**「只含 1、还没接 2」** 那种会在扫第二个 `2` 时消失，`12` 会少算。  
所以：新表 `ng` 先拷一份旧表 `g`（表示都不选 ch），再往 `ng[diff+d]` 上叠加「接了 ch」的方案。

扫完整串后，**g[0]**（即 diff=0）就是 balanced 的条数。

#### 2.5 手推：s = "12"（对应上面的表 g[diff]）

| 扫到 | 发生的事 | g 里非零（记 diff → 条数） |
|------|----------|------------------------------|
| 初始 | 还没有子序列 | 全 0 |
| 扫完 `1` | 新开单独 `{1}`，奇 1 偶 0 → diff=+1 | +1 → 1 条 |
| 扫完 `2` | ① 不选 2：仍有一条 diff=+1（`{1}`）<br>② `{1}` 后接 2 → `{12}`，diff=0<br>③ 新开 `{2}`，diff=-1 | 0→1，+1→1，-1→1 |

结束 **g[0]=1**，即 balanced 只有 `{12}` 这一条。  
§1 的 total=3（`1`,`2`,`12`），答案 = 3−1 = **2**。

#### 2.6 现在再对代码：变量名一览

搞清 2.1～2.5 之后，代码只是把同一张表写进数组：

| 名字 | 对应上面哪句话 |
|------|----------------|
| **g** | 扫完 **上一个** 字符后的表 `g[diff]` |
| **ng** | 扫完 **当前** ch 后的新表（new g），算完 `g=ng` |
| **ch** | 当前字符 |
| **d** | ch 的奇偶对 diff 的贡献（+1 / -1） |
| **diff** | 奇数位个数 − 偶数位个数 |
| **cnt** | 旧表里 `g[diff]` 的条数 |
| **off** | 数组下标 = diff + off |

```python
ng = g[:]                      # 不选 ch：旧方案全保留
d = parity_delta(ch)
for diff in ...:
    cnt = g[diff + off]
    if cnt:
        ng[diff + d + off] += cnt   # 旧方案末尾接上 ch
if ch != "0":
    ng[d + off] += 1                # 只选 ch，新开一位
g = ng
return g[off]                  # diff==0：平衡
```

### 3. 第三步：合并

```
ans = (total - g[0]) % (1e9+7)
```

减法后若负，加 MOD。

**复杂度**：O(n * n) 状态维度（diff 范围 O(n)）；n 很大时可用 map 只存非零 diff。

**易错点**：

- 把「子序列」当成连续子串。
- 忘记单字符 `0` 是不平衡的。
- 模运算减法要 `+ MOD`。

#### 1.6 `pow(2, n-1-i, MOD)` 是啥？为啥边算边取模？

`pow(a, b, m)` 是 Python 内置：**算 a^b 再对 m 取余**，内部用快速幂，复杂度 O(log b)，结果始终在 `0..m-1`。

这里 `a=2, b=n-1-i, m=MOD`，即 **2^(n-1-i) mod (1e9+7)**，就是「后面 n-1-i 位各选不选」那种数的个数，在模意义下的值。

**不能先算 `2**(n-1-i)` 最后再 `% MOD` 的原因**：

1. **幂本身太大**：n 可到 1e5 时，`2^100000` 是天文数字（几十万位），存不下、也算不动。
2. **累加和也会爆**：就算只加几项，不把每一项先 mod 掉，中间 `ans` 也会巨大。
3. **数学上允许分步 mod**：`(ans + 项) % MOD` 等价于最后对总和取模，但**每一项必须先 mod 好**。

所以写法是：

```python
ans = (ans + pow(2, n - 1 - i, MOD)) % MOD
```

不是「最后统一 `% MOD` 一次」不行，而是 **幂必须在 pow 里就 mod**；和可以边加边 `% MOD`（推荐，防止 ans 越界）。

若 n 很小（如 n<=60），可以 `ans += 1 << (n-1-i)` 再最后 `% MOD`；竞赛数据大时必须用三参数 `pow`。

## 参考实现

```python
MOD = 10**9 + 7


def parity_delta(ch: str) -> int:
    return 1 if int(ch) & 1 else -1


def count_balanced_multidigit(s: str) -> int:
    """数：首位非0 且 奇数位个数==偶数位个数 的子序列条数。"""
    n = len(s)
    off = n              # diff ∈ [-n, n] → 下标 diff+off ∈ [0, 2n]；n+2 也行，多留边距
    size = 2 * n + 1
    g = [0] * size       # g[diff]: 处理完已扫部分后，diff 对应的子序列条数

    for ch in s:
        ng = g[:]        # new g：先假设不选 ch，旧状态全保留
        d = parity_delta(ch)   # 当前位若选：奇数 +1，偶数 -1

        for diff in range(-n, n + 1):
            cnt = g[diff + off]           # 旧状态里 diff 有多少条
            if cnt:
                # 在每条旧子序列后面接上 ch → diff 变成 diff+d
                ng[diff + d + off] = (ng[diff + d + off] + cnt) % MOD

        if ch != "0":
            # 只选当前位，单独成一条（首位非0，长度1）
            ng[d + off] = (ng[d + off] + 1) % MOD

        g = ng             # 本轮结束，进入下一个字符

    return g[off]          # diff==0：奇偶位个数相等


def total_valid(s: str) -> int:
    n = len(s)
    ans = 0
    for i, ch in enumerate(s):
        if ch == "0":
            ans += 1
        else:
            ans = (ans + pow(2, n - 1 - i, MOD)) % MOD
    return ans


def solve(s: str) -> int:
    bal = count_balanced_multidigit(s)
    return (total_valid(s) - bal) % MOD


def main() -> None:
    s = input().strip()
    print(solve(s))


if __name__ == "__main__":
    main()
```
