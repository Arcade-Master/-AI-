# 08｜淘汰赛观察值最大

**标签**：贪心 / 排序  
**来源**：代码题截图 `已处理/08-淘汰赛观察值-题面.png`  
**状态**：可背

---

## 题面

n 支队伍，能力值 a_i 两两不同。淘汰赛规则：

- 每轮开始时记录**观察值** = 当前仍在场的所有队伍能力值之和；
- 偶数人：全部两两配对，能力强者晋级；
- 奇数人：你指定一人**轮空**直接晋级，其余配对，强者晋级；
- 可自由安排配对与轮空；
- 直到剩 1 人为止（最后剩 1 人不再记观察值）。

求观察值总和的最大值。

**输入**：多测 T；每组 n 与 n 个能力值。sum n <= 5e5。  
**输出**：每组一个整数。

---

## 思路

观察值 = 每轮**开场**时在场队伍能力值之和。等价于：队伍 i 贡献 `a_i × 存活轮数`，要让**强者多留几轮**（每轮加的总和更大）。

`a.sort(reverse=True)` → **降序**（大的在前）：`a[0]` 最强，`a[-1]` 最弱。

模拟用 `alive` 存下标（0 最强，末尾最弱）：

```
每轮：total += 当前 alive 里所有 a[i]
若人数为奇数：alive.pop()     # 从列表末尾弹出 = 淘汰当前最弱（不是轮空晋级！）
alive = alive[: len(alive)//2] # 只保留前半 = 保留较强的一半
```

**语法**：

| 写法 | 含义 |
|------|------|
| `sort(reverse=True)` | **降序**，从大到小 |
| `list.pop()` | 无参数时删 **最后一个**（这里 = 最弱） |
| `len // 2` | 整除，**向下取整**（7//2=3） |

### 奇数轮为啥 `pop` 最弱？（不是「弱队轮空」）

题面轮空 = 某人**不进配对、直接进下一轮**。  
代码里 `pop()` 是 **直接把最弱从 alive 删掉**，等于奇数轮**多淘汰一个最弱的**，不是让他白捡一轮。

为啥可以这么干（直觉）：

- 观察值要最大化 → 希望**后面每轮的 sum 尽量大** → 场上尽量剩强者。
- **最弱的多待一轮**，下一轮 sum 只多加一点点他的能力值，还占一个名额；**不如本轮就送走**。
- 所以你说的「弱队轮空留到下一轮被强者淘汰」——若真轮空给弱队，确实不太优；**这题实现是奇数轮顺手多淘汰最弱，不是弱队轮空**。

偶数轮 `alive[:n//2]`：等价于最优配对下**弱的一半全输**（强 always 赢），只留强的一半。

**复杂度**：排序 O(n log n)，模拟 O(n)。

---

## 参考实现

```python
def max_observation(a: list[int]) -> int:
    a.sort(reverse=True)          # 降序：a[0] 最强
    alive = list(range(len(a)))   # alive[-1] 当前最弱
    total = 0
    while len(alive) > 1:
        total += sum(a[i] for i in alive)
        if len(alive) % 2 == 1:
            alive.pop()           # 奇数：删末尾 = 淘汰最弱
        alive = alive[: len(alive) // 2]  # 保留较强的一半
    return total


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(max_observation(a))


if __name__ == "__main__":
    main()
```
