# 08｜淘汰赛观察值最大

**标签**：贪心 / 排序

**状态**：可背

## 题面

n 支队伍，能力值 a_i 两两不同。淘汰赛规则：

- 每轮开始时记录**观察值** = 当前仍在场的所有队伍能力值之和；
- 偶数人：全部两两配对，能力强者晋级；
- 奇数人：你指定一人**轮空**直接晋级，其余配对，强者晋级；
- 可自由安排配对与轮空；
- 直到剩 1 人为止（最后剩 1 人不再记观察值）。

求观察值总和的最大值。

**输入**：多测 T；每组 n 与 n 个能力值。sum n <= 5e5。  
**输出**：每组一个整数。

---

## 思路

### 1. 目标

每个队 i 若在场上存活 t_i 轮「开场」，就贡献 a_i * t_i。  
要最大化总和 = 让**能力强**的队伍尽量多轮留在场上。

### 2. 贪心策略

能力值降序排序后：

- **奇数轮空**：给当前**最弱**的存活者轮空（避免强者在内部互撞淘汰）；
- **偶数配对**：把当前存活序列按「最弱 vs 次弱」配对（或等价：每轮淘汰较弱的一半，保留较强的一半）。

实现：维护存活下标列表 `alive`（0 最强，末位最弱）：

```
每轮 total += sum(a[i] for i in alive)
若 len 为奇：pop 最弱
配对：只保留前半（较强的一半）
```

### 3. 正确性直觉

弱队尽早淘汰可减少「占坑」轮数；强队尽量进前半区多活几轮。  
每轮最多淘汰约一半，强队存活轮数 ≈ ceil(log2(n)) 量级。

**复杂度**：排序 O(n log n)，模拟每轮缩短 O(n)，总 O(n log n)。

---

## 参考实现

```python
def max_observation(a: list[int]) -> int:
    a.sort(reverse=True)
    alive = list(range(len(a)))
    total = 0
    while len(alive) > 1:
        total += sum(a[i] for i in alive)
        if len(alive) % 2 == 1:
            alive.pop()
        alive = alive[: len(alive) // 2]
    return total


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(max_observation(a))


if __name__ == "__main__":
    main()
```
