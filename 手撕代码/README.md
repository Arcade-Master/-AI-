# 手撕代码

与 [`面试笔记/`](../面试笔记/) 分开：**面试笔记** 讲原理与口述；**本目录** 只放手撕实现（Python / NumPy / PyTorch 等）。

| 位置 | 内容 |
|------|------|
| `面试笔记/01-…` 等 | 概念 + 少量参考代码（与知识点绑在一起） |
| **本目录** | 独立题库：多解法、复杂度、边界、可运行片段 |

若某题在笔记里已有（如 01 里的 DFS、第 k 大），可在此 **另开一题** 写更完整版，或在题头链到笔记章节。
