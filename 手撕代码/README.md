# 手撕代码

与 [`面试笔记/`](../面试笔记/) 分开：**面试笔记** 讲原理与口述；**本目录** 只放手撕实现（Python / NumPy / PyTorch 等）。

**书写约定**：公式用纯文本或代码块（如 `n*(n+1)/2`、`O(n)`），**不用 LaTeX**（`\( \)`、`\[ \]`），方便在普通 Markdown 预览里直接阅读。  
**代码输入**：竞赛常用 `int(input())`、`n, k = map(int, input().split())`、`input().split()`，少用 `sys.stdin` 一次性读入。

| 位置 | 内容 |
|------|------|
| `面试笔记/01-…` 等 | 概念 + 少量参考代码（与知识点绑在一起） |
| **本目录** | 独立题库：多解法、复杂度、边界、可运行片段 |
| **[AI手撕/](./AI手撕/)** | DL 算子手撕：交叉熵、多头注意力等（NumPy），与算法题编号分开 |

若某题在笔记里已有（如 01 里的 DFS、第 k 大），可在此 **另开一题** 写更完整版，或在题头链到笔记章节。概念讲解仍以 `面试笔记/` 为主，**AI手撕** 侧重可运行代码与形状。
