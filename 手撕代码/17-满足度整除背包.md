# 17｜满足度整除背包

**标签**：DP / 背包  
**来源**：截图题  
**难度**：中等  
**状态**：可背

---

## 题面

n 道菜，第 i 道有饱腹值 `a_i`、满足度 `b_i`。选若干道（每道最多 1 次），满足：

1. 总饱腹 `sum a_i <= m`；
2. 总满足 `sum b_i` 是 x 的倍数（即 `sum b_i % x == 0`）。

在满足 1 的前提下，最大化总满足度；输出该最大值。

**约束**：1<=n,m<=5e5，**n*m<=5e5**，1<=x<=10，1<=a_i<=m，1<=b_i<=1e9。

---

## 思路

### 要算什么

在「每道菜最多选一次、总饱腹不超过 m」的前提下，让**总满足度尽量大**，且总满足度必须是 **x 的倍数**。

### 分几步

1. 当成 **0/1 背包**：重量 = 饱腹 `a`，价值 = 满足 `b`。
2. 多加一维状态，记录「当前总满足度 mod x 的余数」，最后只取余数为 0 的格子。
3. 内层对饱腹 `w` **倒序**枚举（标准 0/1 背包写法，防止同一道菜用两次）。

### 为什么要多一维 `r`

如果只记「饱腹 w 下满足度最大」，不知道余数，最后无法判断能不能被 x 整除。  
所以再记 **`r = 当前总满足度 % x`**，终态要 **`r == 0`**。

### `dp[w][r]` 表示什么

**只考虑已经处理过的那些菜**（外层 `for` 到第几道菜，表就是几道菜以内的最优）：

`dp[w][r]` = 总饱腹**恰好**为 w、总满足度 mod x **余 r** 时，能达到的**最大总满足度**。

- 达不到的格子填 **-1**（满足度 b 很大，不能用 0 表示「没选」）。
- 初值：什么都没选 → `dp[0][0] = 0`。

### 手推（看懂转移在干啥）

设 `x=3`，先处理菜 A：饱腹 `a=2`，满足 `b=4`。

| 操作 | 含义 |
|------|------|
| 从 `dp[0][0]=0` 选 A | 饱腹 0+2=2，满足 0+4=4，余数 4%3=**1** |
| 更新 | `dp[2][1] = 4` |

再处理菜 B：饱腹 `a=1`，满足 `b=2`。想凑饱腹 `w=3`、余数 `r=0`：

- 若先吃了 A：状态是 `dp[2][1]=4`（饱腹 2，余 1）。
- 再选 B：饱腹 2+1=**3**，余数 (1+2)%3=**0**，满足度 4+2=**6**。
- 即 `dp[3][0] = dp[2][1] + 2 = 6` → 合法（是 3 的倍数），答案可取 6。

对应到式子：从 **`(w-a, r)`** 选当前菜，落到 **`(w, (r+b)%x)`**，满足度加 `b`。

### 转移方程（对照上面例子）

处理当前菜 `(a, b)` 时：

```
nr = (r + b) % x
dp[w][nr] = max(dp[w][nr], dp[w-a][r] + b)
```

白话：**若之前能在饱腹 `w-a`、余数 `r` 下拿到满足度 `dp[w-a][r]`，那再选这道菜就到饱腹 `w`、余数 `nr`，满足度是 `dp[w-a][r] + b`。**

### 为什么 `w` 要倒序（`range(m, a-1, -1)`）

**不是「倒推 DP」**，而是 **0/1 背包同一道菜只能用一次** 的技巧。

- **谁决定「选了哪几道菜」**：外层 `for a, b in items`，每进一轮只讨论「要不要选当前这道菜」；这一轮开始前，`dp` 里只有**前面那些菜**的结果。
- **内层 `w` 为何倒序**：更新 `dp[w]` 时要读 `dp[w-a]`。若 **w 从小到大**，小的 `dp[w-a]` 可能**本轮刚被当前菜更新过**，再被大的 `w` 读走 → **同一道菜链式用两次**。

**反例（正序，只有一道菜 a=3, b=5, m=6）**：

1. `w=3`：`dp[3] = dp[0]+5 = 5`（已选这道菜）
2. `w=6`：`dp[6] = dp[3]+5 = 10`（又从已含该菜的 `dp[3]` 转移）→ **用了两次**

**倒序**：先算 `w=6` 时 `dp[3]` 还是旧值；再算 `w=3` 才写入 5 → **只用一次**。

**`range(m, a-1, -1)`**：Python 里从 `m` 递减到 **`a`**（不到 `a-1`）；只有 `w>=a` 时才有合法的 `w-a`。

`r` 那层 `for r in range(x)` 正序即可，和「重复选菜」无关。

### 答案

所有菜处理完后，在 **饱腹 0..m、余数 0** 里取最大满足度：`max(dp[w][0])`。  
若全是 -1（凑不出），输出 **0**。

**复杂度**：时间 O(n*m*x)，空间 O(m*x)。`n*m<=5e5` 且 `x<=10` 可过。

**易错点**：

- 余数维是 **mod x**，不是随便取模；
- **-1** 表示不可达，不要和满足度 0 混淆；
- 0/1 背包：**w 倒序**；完全背包才改 **w 正序**。

## 参考实现

```python
def max_satisfaction(n: int, m: int, x: int, items: list[tuple[int, int]]) -> int:
    neg = -1
    dp = [[neg] * x for _ in range(m + 1)]
    dp[0][0] = 0  # 不选任何菜

    for a, b in items:  # 外层：正在决定「当前这道菜选不选」
        for w in range(m, a - 1, -1):  # 倒序：保证 dp[w-a] 是「还没选当前菜」时的旧值
            for r in range(x):
                if dp[w - a][r] == neg:
                    continue
                nr = (r + b) % x
                # 选当前菜：从 (w-a,r) 到 (w,nr)，满足度 +b
                dp[w][nr] = max(dp[w][nr], dp[w - a][r] + b)

    best = max(dp[w][0] for w in range(m + 1))  # 饱腹<=m 且总满足是 x 的倍数
    return best if best != neg else 0


def main() -> None:
    n, m, x = map(int, input().split())
    items = [tuple(map(int, input().split())) for _ in range(n)]
    print(max_satisfaction(n, m, x, items))


if __name__ == "__main__":
    main()
```

## 变体 / 追问

- x 很大：开不起余数维，需别的做法（本题 x<=10 就是为 DP 准备）。
- 完全背包（同一道菜可重复选）：内层 **w 正序**。
