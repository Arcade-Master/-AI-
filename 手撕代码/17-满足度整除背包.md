# 17｜满足度整除背包

**标签**：DP / 背包  
**来源**：截图题  
**难度**：中等  
**状态**：可背

---

## 题面

n 道菜，第 i 道有饱腹值 `a_i`、满足度 `b_i`。选若干道（每道最多 1 次），满足：

1. 总饱腹 `sum a_i <= m`；
2. 总满足 `sum b_i` 是 x 的倍数（即 `sum b_i % x == 0`）。

在满足 1 的前提下，最大化总满足度；输出该最大值。

**约束**：1<=n,m<=5e5，**n*m<=5e5**，1<=x<=10，1<=a_i<=m，1<=b_i<=1e9。

---

## 思路

**一句话**：0/1 背包，状态多加一维「满足度 mod x」。

### 状态

`dp[w][r]` = 总饱腹不超过 w、总满足 mod x 余 r 时的最大满足度。  
初值 `dp[0][0]=0`，其余 -1 表示不可达。

### 转移

对每个物品 `(a,b)`，w 从 m 倒序到 a：

```
nr = (r + b) % x
dp[w][nr] = max(dp[w][nr], dp[w-a][r] + b)
```

### 答案

`max(dp[w][0])`，w=0..m。若全不可达（仍为 -1）则输出 **0**（不选任何菜）。

**复杂度**：时间 O(n*m*x)，空间 O(m*x)。由 n*m<=5e5、x<=10 可过。

**易错点**：

- 余数维必须 mod x，不是 mod 大质数；
- b 很大，用 -1 表示不可达，不要用 0 当「没选」；
- 01 背包 w 必须倒序。

---

## 参考实现

```python
def max_satisfaction(n: int, m: int, x: int, items: list[tuple[int, int]]) -> int:
    neg = -1
    dp = [[neg] * x for _ in range(m + 1)]
    dp[0][0] = 0

    for a, b in items:
        for w in range(m, a - 1, -1):  # 01 背包倒序
            for r in range(x):
                if dp[w - a][r] == neg:
                    continue
                nr = (r + b) % x
                dp[w][nr] = max(dp[w][nr], dp[w - a][r] + b)

    best = max(dp[w][0] for w in range(m + 1))
    return best if best != neg else 0


def main() -> None:
    n, m, x = map(int, input().split())
    items = [tuple(map(int, input().split())) for _ in range(n)]
    print(max_satisfaction(n, m, x, items))


if __name__ == "__main__":
    main()
```

---

## 变体 / 追问

- 若 x 很大：不能开余数维，需别的结构（本题 x<=10 就是为 DP 准备）。
- 完全背包：内层 w 改正序。
