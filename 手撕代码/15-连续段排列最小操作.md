# 15｜连续段排列最小操作

**标签**：贪心 / 排序 / 枚举  
**来源**：截图题  
**难度**：中等  
**状态**：可背

---

## 题面

给定长 n 的整数数组 a。先选一个整数 x（全程不变），再通过若干次操作把 a 变成区间 `[x, x+n-1]` 上每个整数**恰好出现一次**的排列（顺序任意）。

单次操作三选一（计 1 次）：

1. 某元素 +1；
2. 某元素 -1；
3. 若某元素已在 `[x, x+n-1]` 内，可一次改成该区间内**任意**整数。

求最优 x 下的最少操作次数；已经满足则输出 0。

---

## 思路

### 要算什么

先定窗口起点 **x**，目标集合是 `{x, x+1, …, x+n-1}`（n 个连续整数各用一次，最终顺序随意）。  
问：**选哪个 x，把数组变过去操作最少**。

### 分几步

1. 排序后，第 i 小的数配目标 **x+i**（匹配问题，不是按原下标）；
2. 对每个候选 x，算每个数挪过去的代价，求和；
3. 取代价最小的 x。

### 小例子（n=2，a=[1,5]）

若 **x=1**，目标 {1,2}：1 已是 1（0 步），5→2 至少 3 步 → 约 3 步。  
若 **x=4**，目标 {4,5}：5→5（0 步），1→4 至少 3 步 → 约 3 步。  
要在多个 x 上比一比，不能凭感觉只试一个。

### 单个数 v 落到目标 t 的代价

- **已在** `[x, x+n-1]`：v==t 则 0，否则操作 3 跳转，代价 1；
- **在左侧** v<x：先进左端点 x，代价 `x-v`；若 t==x 不再跳，否则 +1；
- **在右侧** v>x+n-1：先进右端点 `x+n-1`，代价 `v-(x+n-1)`；若 t==x+n-1 不再跳，否则 +1。

### 怎么配对

最终顺序任意，但要决定**谁变成哪个目标数**。  
排序 `sa[0]<=…<=sa[n-1]`，让 `sa[i]` 配 `x+i`（小的配小的目标，不会交叉更优）。

### 为啥枚举 `x = sa[j] - i`

总代价随 x 是分段线性的，**最小值一定落在断点**上。  
断点 = 某个目标槽 `x+i` 正好等于某个 `sa[j]`，即 **x = sa[j] - i**。

- **i、j 都是下标**，不是两个数组；`sa[i]-i` 只是 j=i 的 n 种情况；
- 必须枚举 **所有** `sa[j]-i`（共 n² 个），只试 `sa[i]-i` 会漏最优 x。

**复杂度**：O(n^3) 枚举+评估；n 大时可改滑动窗口优化。

**易错点**：

- 操作 3 只对**已在区间内**的数；
- 右端点是 `x+n-1`，不是 `x+n`；
- 配对按**排序后大小**，不是原下标。

## 参考实现

```python
def min_ops(a: list[int]) -> int:
    n = len(a)
    sa = sorted(a)

    def cost(x: int) -> int:
        total = 0
        for i in range(n):
            v, t = sa[i], x + i
            if v < x:
                total += x - v + (0 if t == x else 1)
            elif v > x + n - 1:
                total += v - (x + n - 1) + (0 if t == x + n - 1 else 1)
            else:
                total += 0 if v == t else 1
        return total

    cands = {sa[j] - i for i in range(n) for j in range(n)}
    return min(cost(x) for x in cands)


def main() -> None:
    n = int(input())
    a = list(map(int, input().split()))
    print(min_ops(a))


if __name__ == "__main__":
    main()
```

## 变体 / 追问

- 无操作 3：代价变 `sum |sa[i]-(x+i)|`。
- x 固定时 O(n) 滑动窗口可优化总复杂度。
