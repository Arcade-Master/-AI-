# 15｜连续段排列最小操作

**标签**：贪心 / 排序 / 枚举  
**来源**：截图题  
**难度**：中等  
**状态**：可背

---

## 题面

给定长 n 的整数数组 a。先选一个整数 x（全程不变），再通过若干次操作把 a 变成区间 `[x, x+n-1]` 上每个整数**恰好出现一次**的排列（顺序任意）。

单次操作三选一（计 1 次）：

1. 某元素 +1；
2. 某元素 -1；
3. 若某元素已在 `[x, x+n-1]` 内，可一次改成该区间内**任意**整数。

求最优 x 下的最少操作次数；已经满足则输出 0。

---

## 思路

**一句话**：把 a 排序后，第 i 小的数应落到目标 `x+i`；对每个候选 x 算总代价，取最小。

### 1. 单个元素 v 落到目标 t 的代价

- **已在区间内** `x <= v <= x+n-1`：若 `v == t` 代价 0，否则用操作 3 跳过去，代价 1。
- **在区间左侧** `v < x`：先加减进到左端点 x，代价 `x-v`；若 `t == x` 不再跳，否则 +1。
- **在区间右侧** `v > x+n-1`：先进右端点 `x+n-1`，代价 `v-(x+n-1)`；若 `t == x+n-1` 不再跳，否则 +1。

### 2. 怎么配对

排序 `sa[0] <= ... <= sa[n-1]`，让 `sa[i]` 匹配 `t_i = x+i`（从小到大依次占坑，不会交叉更优）。

### 3. 枚举 x

`x` 的有效范围约为 `[min(a)-n+1, max(a)]`。  
代价关于 x 是「凸的区间距离和 + 少量 +1 跳变」，在 **n 个候选** `x = sa[i] - i`（让某个 `sa[i]` 正好对齐目标）上取最小即可；每个候选 O(n) 评估。

**复杂度**：时间 O(n^2)（n 个候选 × n 评估），空间 O(n)。

**易错点**：

- 操作 3 只在**已进入区间后**才能用，区间外的元素不能一步跳到内部任意值；
- 右端点匹配条件是 `t == x+n-1`，不是 `x+n`；
- 排序后按下标配对，不要按原下标配。

---

## 参考实现

```python
def min_ops(a: list[int]) -> int:
    n = len(a)
    sa = sorted(a)

    def cost(x: int) -> int:
        total = 0
        for i in range(n):
            v, t = sa[i], x + i
            if v < x:
                total += x - v + (0 if t == x else 1)
            elif v > x + n - 1:
                total += v - (x + n - 1) + (0 if t == x + n - 1 else 1)
            else:
                total += 0 if v == t else 1
        return total

    # 候选 x：让 sa[i] 对齐 x+i，即 x = sa[i]-i
    best = min(cost(sa[i] - i) for i in range(n))
    return best


def main() -> None:
    n = int(input())
    a = list(map(int, input().split()))
    print(min_ops(a))


if __name__ == "__main__":
    main()
```

## 变体 / 追问

- 若只能 +1/-1、没有区间跳转：变成排序后 L1 匹配，总代价 `sum |sa[i]-(x+i)|`。
- x 固定时能否 O(n) 滑动窗口维护代价：可以，但面试写候选枚举更稳。
