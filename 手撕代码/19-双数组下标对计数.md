# 19｜双数组下标对计数

**标签**：哈希 / 前缀计数  
**来源**：截图题  
**难度**：简单  
**状态**：可背

---

## 题面

给定三个长 n 数组 a、b、c（`c_j` 是 b 的下标，1-indexed）。  
统计有序对 `(i,j)` 满足：

1. `1 <= i <= j <= n`；
2. `a_i = b_{c_j}`。

**输入**：多组 T；每组 n 和三行数组。  
**约束**：T<=2e5，n 总和 <=2e5。

---

## 思路

**一句话**：先算 `d_j = b[c_j]`，再扫 j，用前缀频次数 `i<=j` 且 `a_i = d_j` 的个数。

### 手推（样例第一组）

a = [1,2,1,2,1]，b = [2,1,3,1,2]，c = [2,1,5,4,3]  
→ d = [b2,b1,b5,b4,b3] = [1,2,2,1,3]

| j | d_j | 前缀 a 中等于 d_j 的 i 个数 |
|---|-----|------------------------------|
| 1 | 1   | 1                            |
| 2 | 2   | 1                            |
| 3 | 2   | 2                            |
| 4 | 1   | 3                            |
| 5 | 3   | 0                            |

合计 7。

### 实现

j 从 1 到 n：  
`ans += freq[d_j]`（当前 freq 只统计 `a_1..a_{j-1}`）；  
然后 `freq[a_j] += 1`。

**复杂度**：时间 O(n)，空间 O(n) 哈希表。

**易错点**：

- `c_j` 是 **1-indexed**，取 b 时要 `c_j - 1`；
- 条件是 `i <= j`，所以先加答案再更新 freq，不能反；
- 值域大，用 dict 不要开数组桶（除非值域小）。

---

## 参考实现

```python
def count_pairs(a: list[int], b: list[int], c: list[int]) -> int:
    n = len(a)
    d = [b[c[j] - 1] for j in range(n)]  # c 是 1-indexed
    freq: dict[int, int] = {}
    ans = 0
    for j in range(n):
        ans += freq.get(d[j], 0)  # 只统计 i < j+1 即 i<=j 且已扫过的前缀
        freq[a[j]] = freq.get(a[j], 0) + 1
    return ans


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        c = list(map(int, input().split()))
        print(count_pairs(a, b, c))


if __name__ == "__main__":
    main()
```

---

## 变体 / 追问

- 若条件改成 `i < j`：同样先 ans 后更新 freq，语义不变（本写法 i 最大为 j-1）。
- 若统计 `a_i = b_j` 的双数组匹配：可换双指针或离线排序。
