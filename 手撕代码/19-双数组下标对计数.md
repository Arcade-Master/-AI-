# 19｜双数组下标对计数

**标签**：哈希 / 前缀计数  
**来源**：截图题  
**难度**：简单  
**状态**：可背

---

## 题面

给定三个长 n 数组 a、b、c（`c_j` 是 b 的下标，1-indexed）。  
统计有序对 `(i,j)` 满足：

1. `1 <= i <= j <= n`；
2. `a_i = b_{c_j}`。

**输入**：多组 T；每组 n 和三行数组。  
**约束**：T<=2e5，n 总和 <=2e5。

---

## 思路

**一句话**：先算 `d_j = b[c_j]`，再扫 j，用前缀频次数 `i<=j` 且 `a_i = d_j` 的个数。

### 手推（样例第一组）

a = [1,2,1,2,1]，b = [2,1,3,1,2]，c = [2,1,5,4,3]  
→ d = [b2,b1,b5,b4,b3] = [1,2,2,1,3]

条件 `i<=j` 且 `a_i=d_j`，合法对为：

- (1,1)：a1=1, d1=1
- (2,2)：a2=2, d2=2
- (2,3)：a2=2, d3=2
- (1,4)、(3,4)：a1=a3=1, d4=1

共 **5** 对。

### 实现

从左扫 j（0-indexed），**先把 `a[j]` 记入 freq，再 `ans += freq[d[j]]`**：

- 更新后 freq 统计的是 `a[0]..a[j]`，对应 1-indexed 的 `a_1..a_{j+1}`；
- 查询 `freq[d[j]]` 时自然包含 `i=j+1` 当且仅当 `a[j]==d[j]`，也包含所有 `i<j+1`。

**复杂度**：时间 O(n)，空间 O(n) 哈希表。

**易错点**：

- `c_j` 是 **1-indexed**，取 b 时要 `c_j - 1`；
- 条件是 **`i <= j`**，必须**先更新 freq 再查**；若先查后更新，会漏掉 `i=j` 的情况；
- 值域大，用 dict 不要开数组桶（除非值域小）。

---

## 参考实现

```python
def count_pairs(a: list[int], b: list[int], c: list[int]) -> int:
    n = len(a)
    d = [b[c[j] - 1] for j in range(n)]  # c 是 1-indexed
    freq: dict[int, int] = {}
    ans = 0
    for j in range(n):
        freq[a[j]] = freq.get(a[j], 0) + 1  # 先纳入 a[j]（含 i=j 的情况）
        ans += freq.get(d[j], 0)
    return ans


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        c = list(map(int, input().split()))
        print(count_pairs(a, b, c))


if __name__ == "__main__":
    main()
```

---

## 变体 / 追问

- 若条件改成 `i < j`（严格小于）：先 `ans += freq[d[j]]` 再更新 freq，且不计 i=j。
- 若统计 `a_i = b_j` 的双数组匹配：可换双指针或离线排序。
