## 题面

一条直线有 n 个路标，位置 1..n，每个为 `L` 或 `R`。

小球从某个起点 s 出发，维护区间 [l, r]，初始 l = r = s。每一步：

- 在区间内选一个**尚未触发过**的位置 p，读路标；
- 若为 `L`：区间向左扩一格，l 变为 l-1（若 l=1 再扩则从小球**左侧出界**）；
- 若为 `R`：区间向右扩一格，r 变为 r+1（若 r=n 再扩则从**右侧出界**）；
- 每个位置的路标**最多触发一次**。

对起点 s = 1, 2, …, n，判断最终从**左**还是**右**出界（或：输出每个起点的出界方向）。

**约束**：n <= 2e5，需 O(n) 一次求出所有答案，不能对每个起点模拟 O(n)（会 TLE）。

---

## 思路

### 1. 核心结论

记 `cntL` = 串中 `L` 的个数。

- **s <= cntL** → 一定从**左**出界  
- **s > cntL** → 一定从**右**出界  

即：左出界起点 A = {1, 2, …, cntL}，右出界 B = {cntL+1, …, n}，二者划分了 1..n。

### 2. 证明要点（左出界）

要从左侧出去，最终要让左边界扩到 l=1，再一步从左出界。

- 从 s 扩到 l=1 需要 **(s-1)** 次向左扩，每次消耗一个 `L`；
- 最后一步从左出界再消耗 **1** 个 `L`；
- 共需 **s** 个 `L`，故必要条件是 `cntL >= s`。

对称地，右出界需要 `cntR >= n-s+1`，即 `n - cntL >= n - s + 1`，化简得 `s >= cntL + 1`。

在「每步消耗新路标、总步数有限」的模型下，上述条件也是充分的（题解标准结论）。

### 3. 实现

1. 扫一遍串得 `cntL`；
2. 对每个 s：若 `s <= cntL` 输出 `L`，否则输出 `R`（或按题目要求输出 LEFT/RIGHT）。

若题目是**构造**串使某类起点左/右出界，一种合法构造是：前 cntL 个 `L` 再接 (n-cntL) 个 `R`（与计数结论一致）。

**复杂度**：时间 O(n)，空间 O(n)（存串与答案）。

**易错点**：

- 不要对每个起点 BFS/模拟，O(n^2) 会超时。
- cntL=0 时所有起点都右出界。

---

## 参考实现

```python
def solve_one(n: int, s: str) -> str:
    cntL = s.count("L")
    return "".join("L" if i <= cntL else "R" for i in range(1, n + 1))


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        print(solve_one(n, s))


if __name__ == "__main__":
    main()
```

**多测输出示例**：若要求对起点 1..n 各输出一个方向，上式得到长度为 n 的 L/R 串；若题目是单起点查询，用 `s <= cntL` 判一次即可。

---

## 变体 / 追问

- 若路标可重复触发，模型变为随机游走/环，结论不同。
- 证明「充分性」时强调：每步消耗新路标，总 L 数上界为 cntL。
