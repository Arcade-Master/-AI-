# 16｜树高度统一最大

**标签**：贪心 / 排序  
**来源**：截图题  
**难度**：中等  
**状态**：可背

---

## 题面

n 棵树排成一排，初始高度 `h_i`。接下来 n 天，每天选一棵**还没剪过**的树剪一次，可把它剪到**不超过当前高度**的任意非负整数。

- 未剪过的树每晚长高 1；
- 剪过的树不再长。

n 天后所有树同高，求这个**统一高度的最大值**。

**输入**：多组 T；每组 n 和 h。  
**约束**：1<=T<=2e5，n 总和 <=4e5，1<=h_i<=1e9。

---

## 思路

### 要算什么

n 天每天剪一棵，未剪的每晚 +1，剪过的固定高度。最后全部一样高，问这个**统一高度 H 最大多少**。

### 分几步

1. **贪心调度**：高的先剪、矮的后剪（让矮树多等几晚长高）；
2. 对每个调度位置算 H 的上界，取 min；
3. 用具体剪法验证上界可达（不能只算式子）。

**一句话**：矮树晚剪 → 排序后 `H <= h[i]+n-1-i` → 答案取 min，并用日程表验证。

### 手推

n=3，h=[2,5,1]（三棵树 T1=2, T2=5, T3=1）。排序得 h'=[1,2,5]（T3, T1, T2）。

**策略**：高的先剪、矮的后剪（让矮树多等几晚长高）。

| 阶段 | T1(初2) | T2(初5) | T3(初1) | 说明 |
|------|---------|---------|---------|------|
| 初态 | 2 | 5 | 1 | |
| 第1天剪 | 2 | **→3** | 1 | 剪最高的 T2 到 H=3，剪后不再长 |
| 第1晚 | 3 | 3 | 2 | 未剪的 T1、T3 各 +1 |
| 第2天剪 | **→3** | 3 | 2 | 剪 T1 到 3 |
| 第2晚 | 3 | 3 | 3 | 只剩 T3 未剪，+1 |
| 第3天剪 | 3 | 3 | **→3** | 剪 T3 到 3 |
| **结束** | **3** | **3** | **3** | 三棵同高，H=3 可达 |

上面是**构造**（证明 H=3 做得到）。下面三行是**上界**（证明 H 不能更大）：

- 最矮的 1（T3）最后一天剪，先长 2 晚 → 剪前高 3，故 H<=3；
- 中间的 2（T1）第 2 天剪，长 1 晚 → 剪前高 3，故 H<=3；
- 最高的 5（T2）第 1 天剪，不生长 → 剪前高 5，故 H<=5（不是瓶颈）。

上界 min 为 3，又有构造 → **答案 = 3**。

### 公式

排序 `h'[0] <= ... <= h'[n-1]`，让 `h'[i]` 在第 **n-i** 天剪（1-indexed：最小的最后剪，最大的第 1 天剪）。

第 `i` 小的树剪前高度 `h'[i] + (n-1-i)`，故

`H <= h'[i] + n - 1 - i` 对所有 i 成立。

**答案** = `min_i (h'[i] + n - 1 - i)`。

**复杂度**：时间 O(n log n)，空间 O(1)。

**易错点**：

- 是**矮树晚剪**，不是高树晚剪；
- 下标 i 从 0 起，第 i 小的树在剪之前共长 `n-1-i` 晚；
- 公式给出的是 H 的**上界**，要确认可达需像手推表那样给出具体剪法（上界 min + 构造）。

---

## 参考实现

```python
def max_uniform_height(h: list[int]) -> int:
    h.sort()
    n = len(h)
    return min(h[i] + n - 1 - i for i in range(n))


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        h = list(map(int, input().split()))
        print(max_uniform_height(h))


if __name__ == "__main__":
    main()
```
