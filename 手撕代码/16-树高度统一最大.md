# 16｜树高度统一最大

**标签**：贪心 / 排序  
**来源**：截图题  
**难度**：中等  
**状态**：可背

---

## 题面

n 棵树排成一排，初始高度 `h_i`。接下来 n 天，每天选一棵**还没剪过**的树剪一次，可把它剪到**不超过当前高度**的任意非负整数。

- 未剪过的树每晚长高 1；
- 剪过的树不再长。

n 天后所有树同高，求这个**统一高度的最大值**。

**输入**：多组 T；每组 n 和 h。  
**约束**：1<=T<=2e5，n 总和 <=4e5，1<=h_i<=1e9。

---

## 思路

**一句话**：越矮的树越晚剪（多等几天长高），排序后算每个位置上界，取 min。

### 手推

n=3，h=[2,5,1]。排序得 [1,2,5]。

- 最矮的 1 最后一天剪，已长 2 天 → 高度 3，可剪到 H 需 H<=3；
- 中间的 2 倒数第 2 天剪，长 1 天 → H<=2+1=3；
- 最高的 5 第 1 天剪 → H<=5。

答案 `min(3,3,5)=3`。

### 公式

排序 `h'[0] <= ... <= h'[n-1]`，让 `h'[i]` 在第 `i+1` 天剪（0-index：最小树最后剪）。

第 `i` 小的树剪前高度 `h'[i] + (n-1-i)`，故

`H <= h'[i] + n - 1 - i` 对所有 i 成立。

**答案** = `min_i (h'[i] + n - 1 - i)`。

**复杂度**：时间 O(n log n)，空间 O(1)。

**易错点**：

- 是**矮树晚剪**，不是高树晚剪；
- 下标 i 从 0 起，第 i 小的树只长 `n-1-i` 天。

---

## 参考实现

```python
def max_uniform_height(h: list[int]) -> int:
    h.sort()
    n = len(h)
    return min(h[i] + n - 1 - i for i in range(n))


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        h = list(map(int, input().split()))
        print(max_uniform_height(h))


if __name__ == "__main__":
    main()
```
