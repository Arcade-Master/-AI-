# 12｜三子棋结果判定

**标签**：模拟  
**来源**：代码题截图 `已处理/12-三子棋判定-题面.png`  
**状态**：可背

---

## 题面

3x3 棋盘，X 先手，O 后手。给定完整落子序列（n 步，坐标 1..3），判断：

| 输出 | 含义 |
|------|------|
| -1 | 非法：占已有格；或一方已胜后仍落子 |
| 0 | X 胜 |
| 1 | O 胜 |
| 2 | 下完无人胜且过程合法 |

**输入**：多测 T；每组 n 与 n 行坐标。3 <= n <= 9。

---

## 思路

按步模拟：奇数步 X，偶数步 O。

每步后：

1. 若 (x,y) 已有子 → -1；
2. 若落子前已有人获胜 → -1；
3. 落子后检查当前方是否三连（横/竖/斜）；
4. 若 n 步结束仍无人胜 → 2；若中途胜且步数用完时胜者已定。

实现：维护 3x3 盘；`win(player)` 检查 8 条线。

---

## 参考实现

```python
def judge(moves: list[tuple[int, int]]) -> int:
    board = [[0] * 3 for _ in range(3)]

    def win(p: int) -> bool:
        for i in range(3):
            if all(board[i][j] == p for j in range(3)):
                return True
            if all(board[j][i] == p for j in range(3)):
                return True
        if all(board[i][i] == p for i in range(3)):
            return True
        if all(board[i][2 - i] == p for i in range(3)):
            return True
        return False

    for step, (x, y) in enumerate(moves):
        p = 1 if step % 2 == 0 else 2  # 1=X, 2=O
        x -= 1
        y -= 1
        if board[x][y]:
            return -1
        if step > 0 and (win(1) or win(2)):
            return -1
        board[x][y] = p
        if win(p):
            return 0 if p == 1 else 1
    return 2


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        moves = []
        for _ in range(n):
            x, y = map(int, input().split())
            moves.append((x, y))
        print(judge(moves))


if __name__ == "__main__":
    main()
```
