# 14｜根到叶数字之和（LC129）

**标签**：二叉树 / DFS  
**来源**：LeetCode 129  
**难度**：简单  
**状态**：可背

---

## 题面

二叉树每个节点取值 0～9。从根到叶的路径可看作一个十进制整数（如 1→2→3 表示 123）。

求所有根到叶路径所表示数字的**总和**。

**约束**：节点数 1～1000。

**样例**：

```
    4
   / \
  9   0
 / \
5   1
```

路径 495、491、40 → 和 1385。

---

## 思路

### 1. 路径数字怎么表示

从根往下走，当前路径值 `val` 更新为：`val = val * 10 + node.val`。

### 2. DFS

- 到叶子（左右子都空）：把 `val` 加入答案；
- 否则递归左右子（存在才走）。

不必回溯修改全局：把 `val` 当参数往下传即可。

### 3. 复杂度

时间 O(n)，空间 O(h) 递归栈，h 为树高。

**易错点**：

- 只有**叶子**才加和，中间节点不加；
- 单节点树：根即叶子，答案为根的值。

---

## 参考实现

```python
from typing import Optional


class TreeNode:
    def __init__(self, val: int = 0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def sumNumbers(root: Optional[TreeNode]) -> int:
    def dfs(node: Optional[TreeNode], val: int) -> int:
        if not node:
            return 0
        val = val * 10 + node.val
        if not node.left and not node.right:
            return val
        return dfs(node.left, val) + dfs(node.right, val)

    return dfs(root, 0)


class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        return sumNumbers(root)
```

## 变体 / 追问

- 返回所有路径字符串：DFS 时拼接，叶子时 collect。
- 路径和为 target 的路径：DFS + 回溯记录路径。
