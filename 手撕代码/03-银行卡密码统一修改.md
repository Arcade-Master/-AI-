## 题面

有 \(n\) 张银行卡，密码均为 **6 位数字**（含前导零）。

**统一修改**：选定位置 \(pos\in\{1,2,3,4,5,6\}\) 与数字 \(d\in\{0,\ldots,9\}\)，把**每张卡**第 \(pos\) 位都改成 \(d\)。

修改后得到新密码集合，求**不同密码个数**的最小值。

**输入**：多测。\(T\) 组；每组 \(n\) 与 \(n\) 个长度为 6 的字符串。  
**约束**：\(1\le T\le 10^5\)，\(\sum n\le 2\times 10^5\)。

**输出**：每组一个整数——最优修改后的最少不同密码数。

---

## 思路

### 1. 选定的 \(d\) 不影响「种类数」

第 \(pos\) 位被统一改成同一个 \(d\) 后，这一位对所有卡**相同**，在区分不同密码时该位**无信息量**。

因此：固定 \(pos\) 后，不同密码由**其余 5 位**组成的模式决定；\(d\) 取什么都行，只需数「去掉第 \(pos\) 位后的 5 位串」有多少种。

### 2. 枚举位置

只有 6 个位置，对每个 \(pos\)：

- 把每张密码变成 `pwd[:pos] + pwd[pos+1:]`（5 字符）；
- 放进 `set` 统计不同个数；
- 答案 = \(\min_{pos} |set|\)。

### 3. 复杂度

每组：\(6 \times n\) 次插入，字符串长度 5，哈希均摊 \(O(1)\)。  
总时间 \(O(\sum n)\)，空间 \(O(n)\)。

**易错点**：

- 误以为要枚举 \(d\in[0,9]\)（10 倍无用枚举）。
- 位置是 1-indexed 题意时，代码里用 0-indexed 切片。

---

## 参考实现

```python
import sys

def min_unique(passwords: list[str]) -> int:
    best = len(passwords)
    for pos in range(6):
        seen = {p[:pos] + p[pos + 1 :] for p in passwords}
        best = min(best, len(seen))
    return best


def main() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    t = int(next(it))
    out = []
    for _ in range(t):
        n = int(next(it))
        pwds = [next(it).decode() for _ in range(n)]
        out.append(str(min_unique(pwds)))
    sys.stdout.write("\n".join(out))


if __name__ == "__main__":
    main()
```

## 变体 / 追问

- 若允许改 \(k\) 个位置，变为选 \(k\) 位掩码后最小等价类数，需 DP/搜索。
- 若每位可改不同数字（非统一），问题完全不同。

## 面试怎么答（30 秒）

「统一改一位后，这一位不再区分卡片，等价于只保留另外 5 位。枚举 6 个位置，每种用 set 数不同 5 元组，取最小。\(O(6n)\)，不用枚举数字 d。」
