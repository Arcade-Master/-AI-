# 22｜位或最大化

**标签**：贪心 / 位运算  
**来源**：截图题（阿里巴巴）  
**难度**：中等  
**状态**：可背

---

## 题面

给定长 n 数组 a，初始 `x = 0`。可无限次操作：

1. 选下标 i 和整数 y，满足 `1 <= y <= a[i]`；
2. `a[i] -= y`，同时 `x = x OR y`（按位或）。

求 x 的最大值。

**输入**：多组 T；每组 n 和 a。  
**约束**：T<=2e5，n 总和 <=2e5，**1<=a[i]<=n**。

**样例**：

```
3
1 2 3  → 3
4
1 1 1 1 → 1
5
5 5 5 5 5 → 7
```

---

## 思路

### 要算什么

多次从某个 `a[i]` 里扣掉正整数 y，同时把 y **或** 进答案 x。问 x 最大能到多少。

### 分几步

从**高位二进制位**往低位试：这一位能不能在 x 里变成 1？能就从某个还够减的 `a[i]` 里扣掉 `2^k`。

### 手推（a=[1,2,3]）

二进制：`1=001, 2=010, 3=011`，总和最多 6，但 OR 不能简单相加。

| 位 k | 2^k | 能否选 | 操作 |
|------|-----|--------|------|
| 2 | 4 | 否 | 没有 a[i]>=4 |
| 1 | 2 | 是 | 从 a[2]=3 扣 2，剩 1，x\|=2 → x=2 |
| 0 | 1 | 是 | 从 a[2]=1 扣 1，x\|=1 → x=3 |

答案 **3**（即 `011`）。

### 为何从高位贪心

OR 每一位独立；高位为 1 比低位全 1 更「值钱」。  
若当前能凑出 `2^k`（存在 `a[i] >= 2^k`），就应选这一位。  
从**当前最大的** `a[i]` 扣 `2^k`，避免小数过早用完、大数浪费。

### 流程（对应代码）

1. `max_bit = n.bit_length()`（因 a[i]<=n，和不会超过约 n 量级）；
2. k 从大到小：若 `max(a) >= 2^k`，从最大下标扣 `2^k`，`ans |= 2^k`。

**复杂度**：时间 O(n * log n)，空间 O(1)。

**易错点**：

- y 必须 >=1，减 `2^k` 时自然满足；
- 同一 `a[i]` 可多次扣，低位继续用剩余；
- 别扫到 60 位，`a[i]<=n` 时 `n.bit_length()` 足够。

---

## 参考实现

```python
def max_or(a: list[int]) -> int:
    n = len(a)
    ans = 0
    max_bit = n.bit_length()  # a[i]<=n，最高有效位
    for k in range(max_bit, -1, -1):
        bit = 1 << k
        i = max(range(n), key=lambda j: a[j])  # 从当前最大的 a[i] 扣，省着用小数
        if a[i] >= bit:
            a[i] -= bit
            ans |= bit
    return ans


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(max_or(a))


if __name__ == "__main__":
    main()
```

---

## 变体 / 追问

- 若 a[i] 可达 1e9：最高位扫到 30 左右。
- 若操作是 XOR 而非 OR：完全不同题。

## 面试怎么答（30 秒）

「按位贪心，高位优先。能凑 2^k 就 ans 或上并从最大的 a[i] 减掉，同一元素可多次用。」
