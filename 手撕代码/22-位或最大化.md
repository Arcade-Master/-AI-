# 22｜位或最大化

**标签**：贪心 / 位运算  
**来源**：截图题（阿里巴巴）  
**难度**：中等  
**状态**：可背

---

## 题面

给定长 n 数组 a，初始 `x = 0`。可无限次操作：

1. 选下标 i 和整数 y，满足 `1 <= y <= a[i]`；
2. `a[i] -= y`，同时 `x = x OR y`（按位或）。

求 x 的最大值。

**输入**：多组 T；每组 n 和 a。  
**约束**：T<=2e5，n 总和 <=2e5，**1<=a[i]<=n**。

**样例**（单组，无 T）：

```
输入：5 3 / 2 4 3 9 6
输出：6
```

**样例**（多组 T）：

```
3
1 2 3  → 3
4
1 1 1 1 → 1
5
5 5 5 5 5 → 7
```

---

## 思路

**一句话**：从高位到低位贪心，能凑出 `2^k` 就 OR 进答案并从某个 `a[i]` 里减掉。

### 为何贪心

OR 每位独立，高位为 1 比低位全 1 更值。  
若当前能凑 `2^k`（存在某个 `a[i] >= 2^k`），就应选这一位：从最大的 `a[i]` 减 `2^k`，避免小元素浪费大数。

### 流程

1. 设 `ans = 0`，`max_bit` 约为 `log2(n)+1`（因 a[i]<=n）；
2. k 从大到小：若存在 `a[i] >= 2^k`，选最大的那个 i，`a[i] -= 2^k`，`ans |= 2^k`。

**复杂度**：时间 O(n log n)（每位扫一遍），空间 O(1)。

**易错点**：

- y 必须 >=1，但贪心减 `2^k` 时自然满足；
- 同一元素可多次操作，减完还能继续凑低位；
- a[i]<=n 决定最高位，别扫到 60 位浪费时间（扫到 18 位左右足够）。

---

## 参考实现

```python
def max_or(a: list[int]) -> int:
    n = len(a)
    ans = 0
    max_bit = n.bit_length()  # a[i]<=n，最高位到这里即可
    for k in range(max_bit, -1, -1):
        bit = 1 << k
        i = max(range(n), key=lambda j: a[j])  # 从当前最大的 a[i] 扣
        if a[i] >= bit:
            a[i] -= bit
            ans |= bit
    return ans


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(max_or(a))


if __name__ == "__main__":
    main()
```

---

## 变体 / 追问

- 若 a[i] 可达 1e9：最高位扫到 30 位左右。
- 若操作是 XOR 而非 OR：完全不同题，不能贪心按位 OR。
