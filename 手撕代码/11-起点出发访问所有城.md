# 11｜起点出发访问所有城（状压 DP）

**标签**：状压 DP / TSP  
**来源**：代码题截图 `已处理/11-起点TSP-题面.png`（2027 春招 AI 研发）  
**状态**：可背

---

## 题面

从「起点」出发访问 n 座城市 1..n 各恰好一次，不能回起点，不能重复访问。

- 起点到城 i 距离 d_i（-1 表示不可达）；
- 城 i 到城 j 距离 a[i][j]（-1 不可达，a[i][i]=0）。

求访问所有城市的**最小总路程**；不可能则 -1。

**约束**：1 <= n <= 16。

---

## 思路

### 1. 状态

n 很小 → 状压 DP。

`dp[mask][i]` = 已访问集合 mask（bit i 表示城 i 已访问），当前在城 i 的最小花费。

- 初值：只访问城 i：`dp[1<<i][i] = d[i]`（d[i]>=0）；
- 转移：从 mask 去掉 i 的状态，加边到未访问的 j；
- 答案：`min(dp[(1<<n)-1][i])`。

### 2. 细节

- 距离用 64 位，INF 用大数；
- 不可达边跳过。

**复杂度**：O(2^n * n^2)。

---

## 参考实现

```python
def min_trip(n: int, d: list[int], a: list[list[int]]) -> int:
    INF = 10**18
    full = (1 << n) - 1
    dp = [[INF] * n for _ in range(1 << n)]

    for i in range(n):
        if d[i] >= 0:
            dp[1 << i][i] = d[i]

    for mask in range(1 << n):
        for u in range(n):
            if dp[mask][u] >= INF:
                continue
            if not (mask >> u) & 1:
                continue
            for v in range(n):
                if mask >> v & 1:
                    continue
                w = a[u][v]
                if w < 0:
                    continue
                nm = mask | (1 << v)
                dp[nm][v] = min(dp[nm][v], dp[mask][u] + w)

    ans = min(dp[full][i] for i in range(n))
    return -1 if ans >= INF else ans


def main() -> None:
    n = int(input())
    d = list(map(int, input().split()))
    a = [list(map(int, input().split())) for _ in range(n)]
    print(min_trip(n, d, a))


if __name__ == "__main__":
    main()
```
