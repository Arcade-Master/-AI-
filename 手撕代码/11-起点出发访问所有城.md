## 题面

从「起点」出发访问 n 座城市 1..n 各恰好一次，不能回起点，不能重复访问。

- 起点到城 i 距离 d_i（-1 表示不可达）；
- 城 i 到城 j 距离 a[i][j]（-1 不可达，a[i][i]=0）。

求访问所有城市的**最小总路程**；不可能则 -1。

**约束**：1 <= n <= 16。

---

## 思路

### 要算什么

从起点出发，每城恰好一次、不回起点，求最短路径；不可达输出 -1。

### 分几步

n<=16 → **状压 DP**：用二进制 mask 表示「哪些城去过」。

### mask 小例子（n=3，城编号 0,1,2）

| mask 二进制 | 十进制 | 含义 |
|-------------|--------|------|
| 001 | 1 | 只去过城 0 |
| 011 | 3 | 去过城 0、1 |
| 111 | 7 | 三城都去过（full） |

`dp[mask][i]` = 已访问集合为 mask、**当前站在城 i** 的最小花费。

### 手推一步

mask=3（011，在城 0、1），当前在城 0，要去城 2：  
新 mask = 3 | (1<<2) = 7，代价 `dp[3][0] + a[0][2]` 更新 `dp[7][2]`。

### 初值 / 答案

- 只从起点直达城 i：`dp[1<<i][i] = d[i]`（d[i]>=0）；
- 答案：`min(dp[full][i])`，full = (1<<n)-1。

### 转移（对应代码双重循环）

对每个 mask、当前城 u，尝试走到未访问的 v：

`dp[mask | (1<<v)][v] = min(..., dp[mask][u] + a[u][v])`

### 细节

- 距离用 64 位，INF 用大数；
- 不可达边跳过。

**复杂度**：O(2^n * n^2)。

---

## 参考实现

```python
def min_trip(n: int, d: list[int], a: list[list[int]]) -> int:
    INF = 10**18
    full = (1 << n) - 1
    dp = [[INF] * n for _ in range(1 << n)]

    for i in range(n):
        if d[i] >= 0:
            dp[1 << i][i] = d[i]

    for mask in range(1 << n):
        for u in range(n):
            if dp[mask][u] >= INF:
                continue

            for v in range(n):
                if mask >> v & 1:
                    continue
                w = a[u][v]
                if w < 0:
                    continue
                nm = mask | (1 << v)
                dp[nm][v] = min(dp[nm][v], dp[mask][u] + w)

    ans = min(dp[full][i] for i in range(n))
    return -1 if ans >= INF else ans


def main() -> None:
    n = int(input())
    d = list(map(int, input().split()))
    a = [list(map(int, input().split())) for _ in range(n)]
    print(min_trip(n, d, a))


if __name__ == "__main__":
    main()
```
