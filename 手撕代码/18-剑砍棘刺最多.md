# 18｜剑砍棘刺最多

**标签**：贪心 / 排序 / 二分  
**来源**：截图题  
**难度**：简单  
**状态**：可背

---

## 题面

n 根棘刺，硬度 `a_i`；剑初始锋利度 K。可任选顺序尝试砍棘刺（每根最多试一次），也可放弃（不耗锋利度）。

- 尝试第 i 根：若当前 `K >= a_i` 则成功，否则失败；
- **无论成败**，尝试后 `K -= 1`（永久 -1）。

求最多能成功砍断几根。

**输入**：多组 T；每组 n,K 和数组 a。  
**约束**：n 总和 <=2e5，1<=K,a_i<=1e9。

---

## 思路

### 要算什么

按任意顺序尝试砍棘刺（可放弃），成功要 `K>=硬度`，**无论成败 K 都 -1**。问最多成功次数。

### 分几步

1. 贪心：先砍硬度小的（越往后 K 越小）；
2. 设砍 m 根，写出第 m 次前的判定；
3. 排序后扫最大 m。

**一句话**：砍 m 根 ⟺ 排序后 `a[m-1] + m - 1 <= K`。

### 为何先砍小的

每砍一次 K 减 1，越往后 K 越小，所以应让**低硬度**棘刺在**高 K** 时砍。

### 判定 m 根能否全成功

排序后取最小的 m 个 `x_1 <= ... <= x_m`。第 j 次尝试前 K 为 `K-(j-1)`，需

`K - (j-1) >= x_j`  ⟺  `K >= x_j + j - 1`。

j 和 x_j 都随 j 增大，最紧的是 j=m：`K >= x_m + m - 1`。

### 求最大 m

排序 a，从大到小试 m：最大满足 `a[m-1] + m - 1 <= K` 的 m（0-index 下 `a[m-1]` 是第 m 小）。

**手推**：K=5，a=[2,1,4,10,3] → 排序 [1,2,3,4,10]。m=3 时第 3 小=3，3+3-1=5<=5 ✓；m=4 时 4+4-1=7>5 ✗ → 答案 **3**。

**复杂度**：时间 O(n log n)，空间 O(1)。

**易错点**：

- 失败也扣 1 点 K，不是只算成功的次数；
- 放弃不扣 K，所以「不砍」优于「硬砍必败的」；
- 下标：第 m 小是 `a[m-1]`（0-index）。

---

## 参考实现

```python
def max_cuts(n: int, k: int, a: list[int]) -> int:
    a.sort()
    ans = 0
    for i in range(n):
        m = i + 1  # 砍 m 根，当前考虑第 m 小的 a[i]
        if a[i] + m - 1 <= k:
            ans = m
    return ans


def main() -> None:
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        print(max_cuts(n, k, a))


if __name__ == "__main__":
    main()
```

## 变体 / 追问

- 若失败不扣 K：可一直试到 K 不够为止，答案 = 满足 `a[i]<=K` 的个数（排序后前缀）。
