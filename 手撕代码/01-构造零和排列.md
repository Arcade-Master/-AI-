## 题面

给定整数 \(n\)，构造长度为 \(n\) 的数组 \(\{a_1,\ldots,a_n\}\)，满足：

1. \(\sum_{i=1}^n a_i = 0\)
2. \(\{|a_1|,\ldots,|a_n|\}\) 是 \(1\sim n\) 的一个排列（每个绝对值恰好出现一次）
3. 对每个 \(i\)：\(-n \le a_i \le n\) 且 \(a_i \ne 0\)

若不存在合法数组输出 `-1`；否则输出任意一组解。

**输入**：多测。第一行 \(T\)；每测一行 \(n\)（\(1\le n\le 2\times 10^5\)，\(\sum n\le 2\times 10^5\)）。  
**输出**：每测一行 `-1` 或 \(n\) 个整数。

**样例**：

```
3
2
3
4
```

```
-1
1 2 -3
1 -2 -3 4
```

---

## 思路

### 1. 等价转化

绝对值固定为 \(1..n\)，只需给每个数分配正负号，使带符号和为 0：

\[
1+2+\cdots+n = \frac{n(n+1)}{2} = S
\]

要能分成两堆和相等，需要 \(S\) 为偶数，即 \(n(n+1)\equiv 0 \pmod 4\)。

| \(n \bmod 4\) | \(S\) 奇偶 | 是否有解 |
|---------------|------------|----------|
| 0 | 偶 | 有 |
| 1 | 奇 | 无 |
| 2 | 奇 | 无 |
| 3 | 偶 | 有 |

**无解**：`n % 4 in (1, 2)` → 输出 `-1`。

### 2. 四元组构造

连续四个数 \(x,x+1,x+2,x+3\) 用符号 **`+ - - +`**：

\[
x - (x+1) - (x+2) + (x+3) = 0
\]

- **`n % 4 == 0`**：从 1 起每 4 个一组套用 `+ - - +`。
- **`n % 4 == 3`**：先处理 \(1,2,3\) 为 `+ + -`（即 `1 2 -3`），剩余 \(4..n\) 按四元组构造。

### 3. 正确性

每组四元组内部和为 0；\(n\equiv 3\) 时前三项和也为 0，故总和为 0。绝对值互不重复且覆盖 \(1..n\)。每个 \(|a_i|\le n\) 且非 0，满足范围。

**复杂度**：时间 \(O(n)\)，空间 \(O(n)\)（或 \(O(1)\) 除输出）。

**易错点**：

- 只判 `n` 偶/奇不够，必须判 `n % 4`。
- \(n=3\) 不能整除 4，要单独写 `1 2 -3` 再处理 4 起。

## 参考实现

```python
import sys

def build(n: int) -> list[int] | None:
    r = n % 4
    if r in (1, 2):
        return None
    ans = [0] * n
    if r == 3:
        ans[0], ans[1], ans[2] = 1, 2, -3
        start = 3
    else:
        start = 0
    i = start
    while i < n:
        x = i + 1
        ans[i] = x
        ans[i + 1] = -(x + 1)
        ans[i + 2] = -(x + 2)
        ans[i + 3] = x + 3
        i += 4
    return ans


def main() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    t = int(next(it))
    out = []
    for _ in range(t):
        n = int(next(it))
        res = build(n)
        if res is None:
            out.append("-1")
        else:
            out.append(" ".join(map(str, res)))
    sys.stdout.write("\n".join(out))


if __name__ == "__main__":
    main()
```

## 变体 / 追问

- 若要求字典序最小/最大，需在构造上再加贪心，本题任意解即可。
- 推广：绝对值为 \(1..n\) 的倍数或给定多重集时，等价于子集和划分问题。
