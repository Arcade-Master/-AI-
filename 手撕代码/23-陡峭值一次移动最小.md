# 23｜陡峭值一次移动最小

**标签**：贪心 / 枚举  
**来源**：截图题  
**难度**：中等  
**状态**：可背

---

## 题面

数组 a 的**陡峭值** = 相邻差的绝对值之和：`sum |a[i]-a[i+1]|`（n=1 时为 0）。

最多做**一次**操作：取出任意一个元素，插入到任意位置（含首尾）。求陡峭值最小值。

**输入**：多组 T；每组 n 和 a。  
**约束**：T<=2e5，n 总和 <=2e5，**1<=a[i]<=n**。

**样例**：a=[1,3,3,2,5] → 原陡峭值 6；把 2 移到 1 和 3 之间得 [1,2,3,3,5]，陡峭值 4。

---

## 思路

### 要算什么

最多移动一个数的位置，让 `sum |相邻差|` 最小。

### 分几步

1. 算原陡峭值 `base`；
2. 枚举**移出**哪个数 a[i]，算删掉它后相邻边变化 `delta_rem`；
3. 把同一个数**插入**最省的位置，算 `best_insert`；
4. `base + delta_rem + best_insert` 取最小（不移动则就是 base）。

### 手推（样例 a=[1,3,3,2,5]）

原陡峭值：|1-3|+|3-3|+|3-2|+|2-5| = 2+0+1+3 = **6**。

移出 **2**（下标 3）：中间删掉 2，边 (3,2) 与 (2,5) 合成 (3,5)，少算 |3-2|+|2-5|，多算 |3-5|，  
`delta_rem = |3-5| - |3-2| - |2-5| = 2 - 1 - 3 = -2`。

把 2 插到 **1 和 3** 之间：新边 |1-2|+|2-3| 代替 |1-3|，  
插入代价 = |1-2|+|2-3|-|1-3| = 1+1-2 = **0**（2 落在 1～3 之间）。

总变化 -2+0 → 新陡峭值 **4**。

### delta_rem（移出）

- 中间 i：`delta_rem = |a[i-1]-a[i+1]| - |a[i-1]-a[i]| - |a[i]-a[i+1]|`
- 首：`-|a[0]-a[1]|`；尾：`-|a[n-2]-a[n-1]|`

### best_insert（插入）

插到 L、R 之间代价 `|L-v|+|v-R|-|L-R|`；若 v 在 L、R 之间则为 **0**。  
用 `cover[v]`（差分）统计有多少条边的值区间盖住 v；移走 a[i] 最多禁 2 条边，否则再试合并缝、首尾、其余边。

**复杂度**：O(n + 值域)，a[i]<=n。

**易错点**：

- 只能移动一次；
- n=2 移来移去陡峭值不变，直接返回 base。

## 参考实现

```python
def min_steepness(a: list[int]) -> int:
    n = len(a)
    if n == 1:
        return 0

    base = sum(abs(a[i] - a[i + 1]) for i in range(n - 1))
    if n == 2:
        return base

    maxv = max(a)
    diff = [0] * (maxv + 2)
    edge_lo: list[tuple[int, int]] = []
    for i in range(n - 1):
        lo, hi = min(a[i], a[i + 1]), max(a[i], a[i + 1])
        edge_lo.append((lo, hi))
        diff[lo] += 1
        diff[hi + 1] -= 1
    cover = [0] * (maxv + 2)
    c = 0
    for v in range(maxv + 1):
        c += diff[v]
        cover[v] = c

    def edge_ins(j: int, v: int) -> int:
        return abs(a[j] - v) + abs(v - a[j + 1]) - abs(a[j] - a[j + 1])

    def best_insert(i: int, v: int) -> int:
        banned = set()
        if i == 0:
            banned.add(0)
        elif i == n - 1:
            banned.add(n - 2)
        else:
            banned.add(i - 1)
            banned.add(i)

        if cover[v] > len(banned):
            return 0
        for j in range(n - 1):
            if j in banned:
                continue
            lo, hi = edge_lo[j]
            if lo <= v <= hi:
                return 0

        best = 10**9
        if i not in (0, n - 1):
            L, R = a[i - 1], a[i + 1]
            best = min(best, abs(L - v) + abs(v - R) - abs(L - R))
        if i != 0:
            best = min(best, abs(v - a[0]))
        if i != n - 1:
            best = min(best, abs(v - a[-1]))
        for j in range(n - 1):
            if j not in banned:
                best = min(best, edge_ins(j, v))
        return best

    ans = base
    for i in range(n):
        v = a[i]
        if i == 0:
            rem = -abs(a[0] - a[1])
        elif i == n - 1:
            rem = -abs(a[n - 2] - a[n - 1])
        else:
            rem = abs(a[i - 1] - a[i + 1]) - abs(a[i - 1] - a[i]) - abs(a[i] - a[i + 1])
        ans = min(ans, base + rem + best_insert(i, v))

    return ans


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(min_steepness(a))


if __name__ == "__main__":
    main()
```

## 变体 / 追问

- 多次移动：难度跳档，通常另建模。

## 面试怎么答（30 秒）

「枚举移哪个数，算删边 delta_rem；插入尽量落在两数之间使代价 0。cover 差分辅助，取 base+delta+insert 最小。」
