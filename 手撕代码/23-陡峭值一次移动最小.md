# 23｜陡峭值一次移动最小

**标签**：贪心 / 枚举  
**来源**：截图题  
**难度**：中等  
**状态**：可背

---

## 题面

数组 a 的**陡峭值** = 相邻差的绝对值之和：`sum |a[i]-a[i+1]|`（n=1 时为 0）。

最多做**一次**操作：取出任意一个元素，插入到任意位置（含首尾）。求陡峭值最小值。

**输入**：多组 T；每组 n 和 a。  
**约束**：T<=2e5，n 总和 <=2e5，**1<=a[i]<=n**。

**样例**：a=[1,3,3,2,5] → 原陡峭值 6；把 2 移到 1 和 3 之间得 [1,2,3,3,5]，陡峭值 4。

---

## 思路

**一句话**：枚举移哪个数；删掉它后算 `delta_rem`；再选最省钱的插入位置（优先插到某条边的 min~max 之间，代价为 0）。

### 1. 原陡峭值

`base = sum |a[i]-a[i+1]|`。n=1 时恒为 0；**不做操作**时答案就是 base（下面 min 会自然保留 base）。

### 2. 移出 a[i] 的变化（delta_rem）

- 中间位置 i：`delta_rem = |a[i-1]-a[i+1]| - |a[i-1]-a[i]| - |a[i]-a[i+1]|`
- 首/尾：少一条边，分别为 `-|a[0]-a[1]|`、`-|a[n-2]-a[n-1]|`

### 3. 最优插入（best_insert）

把值 v 插到相邻两项 L、R 之间，新增代价 = `|L-v|+|v-R|-|L-R|`。  
若 `min(L,R) <= v <= max(L,R)`，上式为 **0**（v 落在 L、R 之间不增加陡峭值）。

预处理 `cover[v]` = 有多少条边 `[min(a[j],a[j+1]), max(...)]` 覆盖 v（差分数组 O(n+值域)）。  
移走 a[i] 时最多禁用 2 条边；若 `cover[v]` 足够大，或还能找到非禁用的覆盖边 → 插入代价 0。  
否则在**合并缝**（移出后的新邻边）、**首尾**、其余边里取最小插入代价。

**答案** = `min_i (base + delta_rem(i) + best_insert(i))`（包含「不移动」= 只取 base）。

**复杂度**：时间 O(n + V)，V=max(a)<=n；空间 O(V)。

**易错点**：

- 只能移动一次，不是删除或只插入；
- 移中间元素后会出现新边 (a[i-1], a[i+1])，插入那里若 v 在两者之间则插入代价 0；
- a[i]<=n，值域小，适合差分统计 cover。

## 参考实现

```python
def min_steepness(a: list[int]) -> int:
    n = len(a)
    if n == 1:
        return 0

    base = sum(abs(a[i] - a[i + 1]) for i in range(n - 1))
    if n == 2:
        return base  # 移一个元素再插回，陡峭值不变

    base = sum(abs(a[i] - a[i + 1]) for i in range(n - 1))
    maxv = max(a)

    # cover[v] = 有多少条边区间覆盖值 v
    diff = [0] * (maxv + 2)
    edge_lo: list[tuple[int, int]] = []  # 每条边的 (lo, hi)
    for i in range(n - 1):
        lo, hi = min(a[i], a[i + 1]), max(a[i], a[i + 1])
        edge_lo.append((lo, hi))
        diff[lo] += 1
        diff[hi + 1] -= 1
    cover = [0] * (maxv + 2)
    c = 0
    for v in range(maxv + 1):
        c += diff[v]
        cover[v] = c

    def edge_ins(j: int, v: int) -> int:
        return abs(a[j] - v) + abs(v - a[j + 1]) - abs(a[j] - a[j + 1])

    def best_insert(i: int, v: int) -> int:
        banned = set()
        if i == 0:
            banned.add(0)
        elif i == n - 1:
            banned.add(n - 2)
        else:
            banned.add(i - 1)
            banned.add(i)

        # 能插到某条非禁用边且 v 落在 [min,max] 内 → 零代价
        if cover[v] > len(banned):
            return 0
        for j in range(n - 1):
            if j in banned:
                continue
            lo, hi = edge_lo[j]
            if lo <= v <= hi:
                return 0

        best = 10**9
        if i not in (0, n - 1):
            L, R = a[i - 1], a[i + 1]
            best = min(best, abs(L - v) + abs(v - R) - abs(L - R))  # 合并缝
        # 插到首尾（按移出后的数组算等价代价）
        if i != 0:
            best = min(best, abs(v - a[0]))
        if i != n - 1:
            best = min(best, abs(v - a[-1]))
        # 极少数 cover 很稀的情况，再扫非禁用边
        for j in range(n - 1):
            if j not in banned:
                best = min(best, edge_ins(j, v))
        return best

    ans = base
    for i in range(n):
        v = a[i]
        if i == 0:
            rem = -abs(a[0] - a[1])
        elif i == n - 1:
            rem = -abs(a[n - 2] - a[n - 1])
        else:
            rem = abs(a[i - 1] - a[i + 1]) - abs(a[i - 1] - a[i]) - abs(a[i] - a[i + 1])
        ans = min(ans, base + rem + best_insert(i, v))

    return ans


def main() -> None:
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(min_steepness(a))


if __name__ == "__main__":
    main()
```

---

## 变体 / 追问

- 允许多次操作：通常变 DP，难度跳档。
- 只能删不能插：只算 `base + max rem`，与插入无关。

## 面试怎么答（30 秒）

「先算原陡峭值。枚举移哪个数，删除会改一条或两条边；插入时若值落在某条现有边的 min-max 之间则零代价。用值域差分统计覆盖次数，O(n) 求最小。」
