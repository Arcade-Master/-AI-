## 题面

给定整数数组 nums、整数 k，返回数组中第 k 个最大的元素（排序意义下第 k 大，不是第 k 个不同元素）。

**要求**：平均时间复杂度 O(n)。

**约束**：1 <= k <= len(nums) <= 1e5，-1e4 <= nums[i] <= 1e4。

**样例**：nums=[3,2,1,5,6,4], k=2 → 5。

---

## 思路

### 1. 为何不能先排序

排序 O(n log n)，题面要求 O(n) 级别。

### 2. 快速选择（Quickselect）

与快排分区相同：选一个 pivot，把数组分成「>= pivot」和「< pivot」。

- 若左边（较大一侧）长度 == k → pivot 就是第 k 大；
- 若左边长度 > k → 只在左边继续找第 k 大；
- 否则在右边找第 (k - 左边长度) 大。

平均 O(n)，最坏 O(n^2)（可随机 pivot 优化）。

### 3. 备选：值域计数 O(n)

nums[i] 范围只有 2e4+1，可开计数数组，从高到低累加，第 k 个落在哪个值。  
适合值域小、需要稳定 O(n) 最坏时。

**易错点**：第 k 大下标是 k-1（若按降序排）；分区时比较方向要一致（找大的一侧）。

## 参考实现

```python
from random import randrange


def findKthLargest(nums: list[int], k: int) -> int:
    def partition(l: int, r: int) -> int:
        pivot = nums[r]
        i = l
        for j in range(l, r):
            if nums[j] >= pivot:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[r] = nums[r], nums[i]
        return i

    target = k - 1
    l, r = 0, len(nums) - 1
    while True:
        p = partition(l, r)
        if p == target:
            return nums[p]
        if p < target:
            l = p + 1
        else:
            r = p - 1


# 多组自测
if __name__ == "__main__":
    print(findKthLargest([3, 2, 1, 5, 6, 4], 2))
```
