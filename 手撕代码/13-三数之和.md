# 13｜三数之和（LC15）

**标签**：数组 / 双指针 / 排序  
**来源**：LeetCode 15  
**难度**：中等  
**状态**：可背

---

## 题面

给定整数数组 nums，找出所有和为 **0** 且不重复的三元组 `[nums[i], nums[j], nums[k]]`（i、j、k 互不相同）。

返回所有三元组列表（顺序任意）。

**约束**：3 <= len(nums) <= 3000，-1e5 <= nums[i] <= 1e5。

**样例**：nums = [-1,0,1,2,-1,-4] → [[-1,-1,2],[-1,0,1]]

---

## 思路

### 1. 为何先排序

固定一个数 nums[i]，问题变成：在 i 右侧找两数之和 = -nums[i]。  
排序后可用双指针，并方便**去重**（相同值只取第一次）。

### 2. 流程

1. 将 nums 升序排序；
2. 枚举左端点 `i`（0 .. n-3）：
   - 若 nums[i] > 0，后面都非负，不可能和为 0，直接 break；
   - 若 i>0 且 nums[i]==nums[i-1]，跳过（去重）；
   - 双指针 `l=i+1`，`r=n-1`，目标和 `target = -nums[i]`；
   - 若 sum < target：l++；sum > target：r--；相等：记录三元组，然后 l、r 同时移动并跳过重复值。

### 3. 复杂度

时间 O(n^2)，空间 O(1)（不计输出与排序栈）。

**易错点**：

- 去重要在 **i** 和 **找到答案后的 l、r** 两处做；
- sum 用 `nums[i]+nums[l]+nums[r]`，别写错下标。

---

## 参考实现

```python
def threeSum(nums: list[int]) -> list[list[int]]:
    nums.sort()
    n = len(nums)
    ans = []
    for i in range(n - 2):
        if nums[i] > 0:
            break
        if i and nums[i] == nums[i - 1]:
            continue
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                ans.append([nums[i], nums[l], nums[r]])
                l += 1
                r -= 1
                while l < r and nums[l] == nums[l - 1]:
                    l += 1
                while l < r and nums[r] == nums[r + 1]:
                    r -= 1
    return ans


# LeetCode 提交形式
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        return threeSum(nums)
```
