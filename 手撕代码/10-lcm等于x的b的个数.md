## 题面

给定正整数 x、a，求正整数 b 的个数，使得 lcm(a, b) = x。

**输入**：多测 T；每组 x, a。1 <= x,a <= 1e9。

---

## 思路

### 1. 必要条件：a 必须整除 x

**a | x** 读作「**a 整除 x**」，意思就是：**x 除以 a 余数为 0**，即 `x % a == 0`。

同理 **b | x** = `x % b == 0`。

为啥 lcm(a,b)=x 时要有 a|x、b|x？

- lcm 是「a 和 b 的**公共倍数里最小的那个**」。
- 若 a 不能整除 x（x 里有 a 没有的质因子），那 x 不可能是 a 的倍数，更不可能是最小公倍数。
- 所以先写：`if x % a != 0: return 0`。

**例子**：x=12, a=7 → 12%7!=0 → 没有这样的 b，答案 0。

---

### 2. 质因子分解（把数拆成质数相乘）

**prod p^e** 就是口语里的：**x 等于若干质数乘起来**，每个质数 p 乘 e 次。

写成式子大家常写 `x = 2^e1 * 3^e2 * 5^e3 ...`，这里不用记 prod 符号，记**例子**就行：

```
x = 12  →  12 = 2^2 * 3^1     （2 出现 2 次，3 出现 1 次）
a = 4   →   4 = 2^2           （只有 2，出现 2 次）
```

记：

- **e**：质数 p 在 **x** 里出现几次（12 里 2 的 e=2）
- **f**：质数 p 在 **a** 里出现几次（4 里 2 的 f=2）
- **g**：质数 p 在 **b** 里出现几次（要求的未知数）

lcm 的规则：**每个质数上，lcm 的次数 = max(f, g)**（a 和 b 谁含得多取谁）。

题目要求 lcm(a,b)=x，所以对每个质数 p 必须有：

```
max(f, g) = e
```

- **f < e**：a 这边不够，b 必须补满 → **g 只能是 e**（1 种）
- **f == e**：a 已经顶满 → b 该位可以是 0,1,...,e → **g 有 e+1 种**

**例子**：x=12=2^2*3^1，a=4=2^2


| 质数  | e (x里) | f (a里) | b 的 g 有几种               |
| --- | ------ | ------ | ----------------------- |
| 2   | 2      | 2      | f==e → 0,1,2 都行，**3 种** |
| 3   | 1      | 0      | f<e → g 必须是 1，**1 种**   |


答案 = 3 * 1 = **3**。可验证 b=3,6,12 时 lcm(4,b)=12。

### 3. 代码在干啥（读代码前看三句）

`**while p * p <= t`**：试除法只需试到 **sqrt(t)**。若 t 有大因子 p，必有个因子 <= sqrt(t)，前面会试到；循环结束后 **剩下的 t 要么是 1，要么是一个 > sqrt 的质数**。

`**if t > 1`**：循环结束后 t 若还不是 1，说明 **还剩一个质因子没处理**（太大，没进 while），单独算 e=1、f。

`**p += 1 if p == 2 else 2`**：2 试完后只试 **3,5,7,9,11…**（奇数）。**9 不是质数没关系**——我们只是拿 p 去除 t，若 `t % 9 != 0` 直接跳过；9 能整除 t 说明 3 早就除干净了，不会发生。

## 参考实现（带注释）

```python
def count_b(x: int, a: int) -> int:
    # x、a 都是十进制整数。求有多少个 b 使 lcm(a,b)=x
    if x % a:
        return 0  # a 不能整除 x，不可能 lcm(a,b)=x

    ans = 1
    t = x       # 拷贝一份 x，不断 t//=p 剥质因子，剥完为止
    p = 2       # 当前尝试的除数，从 2 开始

    # 为什么 p*p <= t：若 t 有因子 d，则 min(d, t/d) <= sqrt(t)
    # 所以只需用 p=2,3,5,... 试到 sqrt(t)；更大的质因子会留在 t 里
    while p * p <= t:
        if t % p == 0:
            # --- 质数 p 在 x 里出现 e 次 ---
            e = 0
            while t % p == 0:
                e += 1
                t //= p   # 整除，去掉一个 p

            # --- 质数 p 在 a 里出现 f 次 ---
            f = 0
            aa = a
            while aa % p == 0:
                f += 1
                aa //= p

            # max(f,g)=e：f<e 时 b 必须含 p^e，只有 1 种；f==e 时 g 可取 0..e
            if f == e:
                ans *= e + 1
            # f < e：ans *= 1，不用写

        # 2 之后只 +2 试奇数（4,6,8 不可能是质因子来源，跳过省时间）
        # 9 会出现，但不是质数：多数时候 t%9!=0 直接跳过；能整除说明 3 早除过了
        p += 1 if p == 2 else 2

    # while 结束后 t 可能是 1，也可能还剩一个「大于 sqrt(原x)」的质数
    # 例：x=2*1000003，试到 p<=1000 时除不尽，最后 t=1000003 留在这里
    if t > 1:
        e = 1          # 这个大质数在 x 里只出现 1 次
        f = 0
        aa = a
        while aa % t == 0:
            f += 1
            aa //= t
        if f == e:     # f==1 时 b 里这个质数次数 0 或 1，共 2 种
            ans *= e + 1

    return ans


def main() -> None:
    t = int(input())
    for _ in range(t):
        x, a = map(int, input().split())
        print(count_b(x, a))


if __name__ == "__main__":
    main()
```

### 走一遍 x=12, a=4

```
t=12, p=2: 2*2<=12，t%2==0 → e=2，t 剥成 3；a 里 f=2 → f==e → ans=3
p=3: 3*3<=3? 否，while 结束（3 留给下面 if t>1）
t=3>1: 大质因子 3，e=1，a 里 f=0 → f<e，ans 仍 3
```
