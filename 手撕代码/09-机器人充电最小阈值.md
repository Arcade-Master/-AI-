## 题面

数轴上 n 个机器人、 m 个充电桩。桩 j 位置 c_j，最多同时服务 cap_j 个机器人。

若机器人与桩距离 <= 阈值 E，则可由该桩充电。

求使**所有机器人都能分配**到桩（不超容量）的**最小整数 E**；无解输出 -1。

**输入**：多测；每组 n,m，机器人坐标，桩坐标，容量。sum(n+m) <= 2e5。

---

## 思路

### 1. 单调性

E 越大，可连边越多，越容易匹配 → 对 E 二分。

### 2. 判定 check(E)

机器人、桩坐标排序后贪心：

- 机器人从小到大处理；
- 指针扫桩，在距离 <= E 且还有容量的桩里给当前机器人分配（常用**最左**可用桩）。

```python
def check(E, robots, piles):
    # piles: list of (c, cap) sorted by c
    cap = [p[1] for p in piles]
    j = 0
    for r in sorted(robots):
        while j < m and piles[j][0] < r - E:
            j += 1
        k = j
        ok = False
        while k < m and piles[k][0] <= r + E:
            if cap[k] > 0:
                cap[k] -= 1
                ok = True
                break
            k += 1
        if not ok:
            return False
    return True
```

线上一维、容量约束下该贪心通常成立；若卡数据可换匈牙利/费用流。

### 3. 二分边界

左 0，右 2e6+（坐标差上界）。若 check(上界) 仍 false → -1。

**复杂度**：O((n+m) log V) 每次 check O(n+m)。

---

## 参考实现

```python
def min_threshold(n, m, robots, piles_pos, caps) -> int:
    piles = sorted(zip(piles_pos, caps))

    def check(E: int) -> bool:
        rem = [c for _, c in piles]
        j = 0
        for r in sorted(robots):
            while j < m and piles[j][0] < r - E:
                j += 1
            k = j
            assigned = False
            while k < m and piles[k][0] <= r + E:
                if rem[k] > 0:
                    rem[k] -= 1
                    assigned = True
                    break
                k += 1
            if not assigned:
                return False
        return True

    hi = 2 * 10**6 + 5
    if not check(hi):
        return -1
    lo = 0
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo


def main() -> None:
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        robots = list(map(int, input().split()))
        piles_pos = list(map(int, input().split()))
        caps = list(map(int, input().split()))
        print(min_threshold(n, m, robots, piles_pos, caps))


if __name__ == "__main__":
    main()
```
