## 题面

给定**环状**二进制串 s（长度 n，仅 `0` / `1`）。任选起点把环「剪开」顺时针读成长度 n 的线性串（即 s 的一个**旋转**）。

对某个旋转，定义 **最短 k-前缀长度**：最短的前缀子串中恰好包含 k 个 `1`；若该线性串中 `1` 总数 < k，则该旋转无解（记 -1）。

求**所有旋转**中，上述长度的**最小值**；若所有旋转都无解，输出 -1。

**输入**：多测。每组 n、k 与串 s。所有 n 之和 <= 2e5。  
**输出**：每组一个整数。

---

## 思路

### 1. 总 1 不足

若串中 `1` 的个数 < k，任意旋转只有 n 位，直接输出 -1。

### 2. 倍串 + 1 的下标

环上旋转 → 在 `s + s` 上取起点 start（0 ～ n-1），只看窗口 [start, start+n-1] 作为该旋转。

从 start 向右数，**第 k 个 1** 的下标记为 end，则最短 k-前缀长度为：

```
len = end - start + 1
```

预处理 `ones` = 在 s+s 中所有 `1` 的下标（升序）。

对每个 start：

- `j = lower_bound(ones, start)`（第一个 >= start 的 1）
- 第 k 个 1 为 `ones[j + k - 1]`
- 若 `ones[j+k-1] > start + n - 1`，该旋转在长度 n 内凑不齐 k 个 1（总 1 数 >= k 时一般不会发生）
- 更新 `ans = min(ans, end - start + 1)`

### 3. 优化（可选）

start 枚举 0..n-1 即可；n <= 2e5 时 O(n log n) 二分或双指针 O(n) 均可。

**复杂度**：时间 O(n) 或 O(n log n)，空间 O(n)。

**易错点**：

- 忘记先判总 1 数。
- 只用原串不倍串，旋转跨尾部时漏算。

## 参考实现

```python
import bisect


def min_k_prefix(n: int, k: int, s: str) -> int:
    if s.count("1") < k:
        return -1
    s2 = s + s
    ones = [i for i, ch in enumerate(s2) if ch == "1"]
    ans = 10**9
    for start in range(n):
        j = bisect.bisect_left(ones, start)
        end = ones[j + k - 1]
        if end > start + n - 1:
            continue
        ans = min(ans, end - start + 1)
    return -1 if ans == 10**9 else ans


def main() -> None:
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        s = input().strip()
        print(min_k_prefix(n, k, s))


if __name__ == "__main__":
    main()
```

- 求「最大值」或「恰好 k 个 0」同理滑动。
