## 题面

给定**环状**二进制串 \(s\)（长度 \(n\)，仅 `0`/`1`）。任选起点把环「剪开」顺时针读成长度 \(n\) 的线性串（即 \(s\) 的一个**旋转**）。

对某个旋转，定义 **最短 k-前缀长度**：最短的前缀子串中恰好包含 \(k\) 个 `1`；若该线性串中 `1` 总数 \(<k\)，则该旋转无解（记 \(-1\)）。

求**所有旋转**中，上述长度的**最小值**；若所有旋转都无解，输出 \(-1\)。

**输入**：多测。每组 \(n,k\) 与串 \(s\)。\(\sum n\le 2\times 10^5\)。

**输出**：每组一个整数。

---

## 思路

### 1. 总 `1` 不足

若 `s.count('1') < k`，任意旋转只有 \(n\) 位，最多也就这些 `1`，直接输出 `-1`。

### 2. 倍串 + 1 的下标

环上旋转 → 在 \(s+s\) 上取起点 `start\in[0,n-1]\)，只看窗口 \([start, start+n-1]\) 内的前 \(n\) 个字符作为该旋转。

在窗口内从 `start` 开始向右数，**第 \(k\) 个 `1`** 的位置记为 `end`，则最短 k-前缀长度为：

\[
\text{len} = end - start + 1
\]

预处理 `ones` = \(s+s\) 中所有 `1` 的下标（升序）。

对每个 `start`：

- `j = lower_bound(ones, start)`
- 第 \(k\) 个 `1` 为 `ones[j+k-1]`
- 若 `ones[j+k-1] > start + n - 1`，该旋转在长度 \(n\) 内凑不齐 \(k\) 个 `1`（当总 `1` \(\ge k\) 时，在环上任意窗口长度 \(n\) 恰有 `total` 个 `1`，故不会发生）
- 更新 `ans = min(ans, ones[j+k-1] - start + 1)`

### 3. 优化（可选）

`start` 只需枚举 `0..n-1`；也可只枚举「第一个 `1` 在窗口起点附近」的候选，但 \(n\le 2\times 10^5\) 时 \(O(n\log n)\) 或双指针 \(O(n)\) 均可。

**双指针写法**：在 `ones` 上滑动，对每个 `start` 找第 \(k\) 个 `1`，均摊 \(O(n)\)。

**复杂度**：时间 \(O(n)\) 或 \(O(n\log n)\)，空间 \(O(n)\)。

**易错点**：

- 忘记先判总 `1` 数。
- 只用原串不倍串，旋转跨尾部时漏算。

## 参考实现

```python
import sys
import bisect


def min_k_prefix(n: int, k: int, s: str) -> int:
    if s.count("1") < k:
        return -1
    s2 = s + s
    ones = [i for i, ch in enumerate(s2) if ch == "1"]
    ans = 10**9
    for start in range(n):
        j = bisect.bisect_left(ones, start)
        end = ones[j + k - 1]
        if end > start + n - 1:
            continue
        ans = min(ans, end - start + 1)
    return -1 if ans == 10**9 else ans


def main() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    t = int(next(it))
    out = []
    for _ in range(t):
        n = int(next(it))
        k = int(next(it))
        s = next(it).decode()
        out.append(str(min_k_prefix(n, k, s)))
    sys.stdout.write("\n".join(out))


if __name__ == "__main__":
    main()
```

## 变体 / 追问

- 若前缀长度可超过 \(n\)（无限循环读），模型变化；本题前缀在剪开后的长度 \(n\) 串内。
- 求「最大值」或「恰好 \(k\) 个 0」同理滑动。
