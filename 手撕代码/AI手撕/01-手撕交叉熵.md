**状态**：可背

---

## 要手撕什么

| 层次 | 输入 | 输出 |
|------|------|------|
| 定义层 | 真实分布 p、预测分布 q | 标量 `-mean( sum_i p_i * log q_i )` |
| 分类训练 | logits z、整数标签 y | 标量 CE（先 softmax 再取 -log q[y]） |
| 工程稳定 | logits z、标签 y | `log_softmax` + `NLL`，避免 `log(softmax)` 精度问题 |

下面按 **「先懂式子 → 再写代码 → 再写稳定版」** 顺序来。

---

## 1. 交叉熵在说什么

真实分布 **p**（one-hot 或软标签），模型预测 **q**（概率，和为 1）：

```
CE = - sum_i  p_i * log(q_i)
```

对一个样本、硬标签类 k：`p_k=1`，其余为 0 → **CE = -log(q_k)**。  
训练要 **让真类概率 q_k 尽量大**，等价于 **让 -log(q_k) 尽量小**。

固定 p 时，最小化 CE 等价于最小化 **KL(p || q)**（p 的熵与参数无关）。

---

## 2. MSE（均方误差）

回归 / 重建常用：

```
MSE = mean( (y - y_hat)^2 )
```

梯度对预测值正比于 `(y_hat - y)`，误差大时更新步子大。分类一般不用 MSE，而用 CE（见上）。

---

## 3. 多分类：softmax + CE（两步版）

logits `z` 形状 `(N, C)`：N 个样本、C 类。

```
q = softmax(z)     # 每行和为 1
loss = mean( -log(q[i, y[i]]) )
```

**softmax 数值稳定**：每行先减该行 max 再 exp，再除以行和。

---

## 4. 二分类（sigmoid + CE）

logit 标量 z，标签 y∈{0,1}：

```
p = sigmoid(z) = 1 / (1 + exp(-z))
loss = -[ y*log(p) + (1-y)*log(1-p) ]
```

sigmoid 也要稳定：z>=0 与 z<0 分两支写，避免 exp 溢出。

---

## 5. 推荐手撕：log_softmax + NLL（一步稳定版）

```
log_q = log_softmax(z)    # 与 softmax 同族稳定技巧
loss = -mean( log_q[i, y[i]] )
```

PyTorch 对应：`F.cross_entropy(logits, y)` 内部即此逻辑。

---

## 形状与 axis（别串维）

| 张量 | 形状 | 说明 |
|------|------|------|
| z / logits | (N, C) | N 样本，C 类 |
| y | (N,) | 整数 0..C-1 |
| softmax / log_softmax | (N, C) | **在最后一维 axis=-1** 做 |

---

## 参考实现（NumPy）

```python
import numpy as np


def mse_loss(y_true: np.ndarray, y_pred: np.ndarray) -> float:
    return float(np.mean((y_pred - y_true) ** 2))


def stable_softmax(z: np.ndarray, axis: int = -1) -> np.ndarray:
    z = z - np.max(z, axis=axis, keepdims=True)
    e = np.exp(z)
    return e / (np.sum(e, axis=axis, keepdims=True) + 1e-12)


def log_softmax(z: np.ndarray, axis: int = -1) -> np.ndarray:
    z = z - np.max(z, axis=axis, keepdims=True)
    log_sum = np.log(np.sum(np.exp(z), axis=axis, keepdims=True) + 1e-12)
    return z - log_sum


def cross_entropy_from_probs(p: np.ndarray, q: np.ndarray, eps: float = 1e-12) -> float:
    """p, q: (N, C) 每行和为 1"""
    q = np.clip(q, eps, 1.0)
    return float(-np.mean(np.sum(p * np.log(q), axis=-1)))


def cross_entropy_logits(z: np.ndarray, y: np.ndarray) -> float:
    """z: (N,C), y: (N,) 整数标签"""
    q = stable_softmax(z, axis=-1)
    n = z.shape[0]
    return float(-np.mean(np.log(q[np.arange(n), y] + 1e-12)))


def cross_entropy_logits_stable(z: np.ndarray, y: np.ndarray) -> float:
    log_q = log_softmax(z, axis=-1)
    n = z.shape[0]
    return float(-np.mean(log_q[np.arange(n), y]))


def binary_cross_entropy_with_logits(z: np.ndarray, y: np.ndarray) -> float:
    """z, y: (N,)"""
    p = np.where(z >= 0, 1.0 / (1.0 + np.exp(-z)), np.exp(z) / (1.0 + np.exp(z)))
    p = np.clip(p, 1e-12, 1.0 - 1e-12)
    return float(-np.mean(y * np.log(p) + (1.0 - y) * np.log(1.0 - p)))


if __name__ == "__main__":
    z = np.array([[2.0, 1.0, 0.1], [0.5, 2.5, 0.3]])
    y = np.array([0, 1])
    print("两步 CE:", cross_entropy_logits(z, y))
    print("稳定 CE:", cross_entropy_logits_stable(z, y))
    # 应与 PyTorch 接近：
    # import torch, torch.nn.functional as F
    # F.cross_entropy(torch.tensor(z), torch.tensor(y, dtype=torch.long))
```

---

## 易错点

- softmax 的 **axis** 必须是「类」那一维，不能对 batch 维做。
- 取 `q[i, y[i]]` 用 `np.arange(n)` 高级索引，不要写错行号。
- 手写 `log(softmax)` 不如 **log_softmax** 稳定。
- 多分类 CE 默认 **mean over batch**；面试说清楚是 sum 还是 mean。

---

## 面试怎么答（30 秒）

「CE 是 -sum p log q；分类里真类 one-hot 就是 -log q_真类。实现上对 logits 做 log_softmax 再取负的 log_q[label]，或 softmax 后取 -log，但要减 max 防溢出。二分类用 sigmoid 版 BCE。」
