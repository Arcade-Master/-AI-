# 02｜手撕多头注意力

**标签**：Transformer / 注意力 / NumPy  
**关联笔记**：[`面试笔记/02-注意力Transformer与Mask.md`](../../面试笔记/02-注意力Transformer与Mask.md) 第 2、6、12 节  
**难度**：中等（维度变换多，建议对着形状表写）  
**状态**：可背

---

## 全文脉络

```
输入 X (B,L,d)
  → 线性投影得 Q,K,V
  → 拆成 n_heads 个头
  → 每头：scores = QK^T / sqrt(dk)，softmax，乘 V
  → 拼回 (B,L,d) → 乘 W_O 输出
```

**B** batch，**L** 序列长，**d** d_model，**H** 头数，**dk** = d / H。

---

## 1. 单头 scaled dot-product

```
scores = Q @ K^T / sqrt(dk)     # (Lq, Lk) 或 (B,H,Lq,Lk)
weights = softmax(scores, 在 key 那一维)
out = weights @ V               # (Lq, dk)
```

**为何除以 sqrt(dk)**：点积方差随 dk 变大，softmax 易饱和；缩放让分数尺度稳定。

**因果 mask（decoder 自注意力）**：位置 i 不能看 j>i，把 `scores[i,j]`（j>i）置为很大的负数，softmax 后权重≈0。

---

## 2. 多头在干什么

把 d 维拆成 H 份，每份 dk 维，**各头独立**做 attention，再 **concat** 起来，最后乘 **W_O (d,d)** 混回 d 维。

```
head_i = Attention(X W_Q^i, X W_K^i, X W_V^i)   # 实现上常拼成大矩阵一次乘
MHA(X) = Concat(head_1, ..., head_H) @ W_O
```

直觉：不同头学不同匹配模式（局部、指代、长距等）。

---

## 3. 形状表（写代码时对着查）

| 步骤 | 形状 |
|------|------|
| X | (B, L, d) |
| Q,K,V = X @ Wq/Wk/Wv | (B, L, d) |
| split heads | (B, H, L, dk) |
| scores | (B, H, L, L) self-attn 时 Lq=Lk=L |
| attn @ V | (B, H, L, dk) |
| merge heads | (B, L, d) |
| @ W_O | (B, L, d) |

---

## 4. 实现要点

- `reshape` + `transpose(0,2,1,3)` 完成拆头 / 合头。
- `matmul` 最后两维是 `(L,dk)` 与 `(L,dk)` 上的注意力。
- softmax 在 **最后一维**（key 维）上做。
- 大矩阵 `Wq,Wk,Wv` 形状 `(d,d)`，与「每头一块小矩阵」等价。

---

## 参考实现（NumPy）

```python
import numpy as np


def softmax_last(x: np.ndarray, axis: int = -1, eps: float = 1e-9) -> np.ndarray:
    x = x - np.max(x, axis=axis, keepdims=True)
    e = np.exp(x)
    return e / (np.sum(e, axis=axis, keepdims=True) + eps)


def scaled_dot_product_attention(
    q: np.ndarray,
    k: np.ndarray,
    v: np.ndarray,
    causal: bool = False,
) -> tuple[np.ndarray, np.ndarray]:
    """
    q: (B, H, Lq, dk)
    k: (B, H, Lk, dk)
    v: (B, H, Lk, dk)
    """
    dk = q.shape[-1]
    scores = np.matmul(q, np.swapaxes(k, -2, -1)) / np.sqrt(dk)  # (B,H,Lq,Lk)
    if causal:
        lq, lk = scores.shape[-2], scores.shape[-1]
        assert lq == lk, "causal self-attn needs Lq == Lk"
        mask = np.triu(np.ones((lq, lk), dtype=bool), k=1)
        scores = np.where(mask, -1e9, scores)
    attn = softmax_last(scores, axis=-1)
    out = np.matmul(attn, v)  # (B,H,Lq,dk)
    return out, attn


def multi_head_attention(
    x: np.ndarray,
    wq: np.ndarray,
    wk: np.ndarray,
    wv: np.ndarray,
    wo: np.ndarray,
    n_heads: int,
    causal: bool = False,
) -> np.ndarray:
    """
    x: (B, L, d)
    wq, wk, wv, wo: (d, d), d % n_heads == 0
    """
    b, l, d = x.shape
    assert d % n_heads == 0
    dk = d // n_heads

    def proj(t: np.ndarray, w: np.ndarray) -> np.ndarray:
        return np.matmul(t, w)  # (B,L,d)

    def split_heads(t: np.ndarray) -> np.ndarray:
        # (B,L,d) -> (B,L,H,dk) -> (B,H,L,dk)
        t = t.reshape(b, l, n_heads, dk)
        return np.transpose(t, (0, 2, 1, 3))

    q = split_heads(proj(x, wq))
    k = split_heads(proj(x, wk))
    v = split_heads(proj(x, wv))

    out, _ = scaled_dot_product_attention(q, k, v, causal=causal)
    # (B,H,L,dk) -> (B,L,d)
    out = np.transpose(out, (0, 2, 1, 3)).reshape(b, l, d)
    return np.matmul(out, wo)


if __name__ == "__main__":
    np.random.seed(0)
    B, L, d, H = 2, 4, 8, 2
    x = np.random.randn(B, L, d)
    wq = wk = wv = wo = np.random.randn(d, d) * 0.02
    y = multi_head_attention(x, wq, wk, wv, wo, H, causal=True)
    print("out shape:", y.shape)  # (2, 4, 8)
```

---

## 易错点

- **K 的转置**：`q @ k^T` 用 `swapaxes(k, -2, -1)`，别在错维上转置。
- **因果 mask** 只挡 **未来** 列（上三角 j>i），不是下三角。
- 合头时 `transpose` 顺序必须是 `(0,2,1,3)`，再 `reshape(b,l,d)`。
- 输出长度跟 **Q** 走（Lq），不是 Lk；cross-attention 时 Lq、Lk 可不同（上面接口已支持）。

---

## 变体 / 追问

- **Cross-Attention**：Q 来自 decoder，K/V 来自 encoder；改输入来源即可，公式不变。
- **KV Cache**：decode 时只算新 token 的 q，k/v 追加缓存（见面试笔记 02 §10）。
- **GQA/MQA**：多 Q 头共享 K/V，为省显存（见面试笔记 06）。

---

## 面试怎么答（30 秒）

「单头：QK^T 除 sqrt(dk)，对 key 维 softmax，再乘 V。多头把 d 拆 H 份并行算，concat 后乘 W_O。训练自注意力加因果上三角 mask。形状记 (B,H,L,dk)，拆头用 reshape+transpose。」
