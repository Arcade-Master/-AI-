# 03｜Adam / AdamW、浮点格式与数值稳定

对应：**第一批**（Adam、FP16 策略）；**第二批**（BF16/FP16/FP32、overflow/underflow、loss scaling、AdamW 与 bias correction）。

---

## 1. Adam：一阶矩、二阶矩到底在估什么？

把每个参数看成独立问题（工程上略粗糙但够用）：

- **一阶矩 m**：梯度 g 的 **指数滑动平均**，像带动量的「平滑梯度方向」。
- **二阶矩 v**：梯度 **逐元素平方** 的指数滑动平均，估的是「该参数梯度历史典型能量/方差量级」。

**更新直觉**（省略 hat 记号）：

```
有效步长 ∝ m / (sqrt(v) + eps)
```

梯度噪声大、历史幅度大的维，分母大 → **自动小步**；一致方向的维，分子累积 → **加速**。这是「自适应学习率」的来源。

---

## 2. bias correction（偏差修正）为什么需要？

初始化 m=0, v=0。前几步真实梯度已进来，但 EMA 仍 **系统性偏小**（被 0 拖着）。若不做修正，早期 **步长过小**，收敛慢。

Adam 用：

```
m_hat = m / (1 - beta1^t)
v_hat = v / (1 - beta2^t)
```

t 小时分母小 → 放大 m、v；t 大后 (1-beta^t)≈1，修正消失。这是 **有限步 EMA 的统计偏差**，不是装饰。

---

## 3. Adam vs AdamW：核心区别

**Adam（原版 L2 理解混乱）**：常见实现把 L2 与梯度混在一起，**weight decay 与自适应学习率耦合**，大梯度维的 decay 行为与「我们以为的 L2」不一致。

**AdamW**：把 **weight decay 从梯度更新里解耦**（decoupled weight decay）：

- 先按 Adam 规则用梯度算一步；
- 再对参数直接乘 `(1 - lr * wd)` 或对参数加 **与梯度无关** 的 shrink。

**面试金句**：AdamW = Adam + **解耦的权重衰减**，使正则强度与自适应缩放 **独立可控**，大模型训练更稳、调参更直观。

---

## 4. BF16 / FP16 / FP32：指数位与尾数位

IEEE 754 风格记忆（面试够用）：

- **FP32**：1 符号 + 8 指数 + 23 尾数，动态范围大、精度高，默认全精度训练基准。
- **FP16**：1 + 5 指数 + 10 尾数。**指数位少** → 可表示的 **数量级范围窄**，大数易 **overflow**，小数梯度易 **underflow**；尾数位少 → 相邻可表示数 **间距大**，累加误差明显。
- **BF16**（bfloat16）：1 + **8** 指数 + **7** 尾数。与 FP32 **同指数宽度** → **动态范围接近 FP32**，大尺度训练更不易炸；尾数更短 → **精度低于 FP32**，但常靠与 FP32 主权重或 loss scaling 搭配弥补。

**为什么 BF16 常「更稳」**：同样「大 logits、大梯度」场景，BF16 更不容易因指数不够而 inf；FP16 需要更依赖 **loss scaling、选择性 FP32 算子**。

**为什么训练常保留 FP32 master weights**：优化器里累加的小更新在 FP16 里可能 **舍入为 0**；用 FP32 存主权重、更新后再 cast，可避免 **长期漂移与不收敛**。

---

## 5. 上溢（overflow）与下溢（underflow）

- **Overflow**：中间结果超过可表示最大值 → inf/NaN，反传全毁。
- **Underflow**：非零梯度/激活被舍入成 0 → **学不动**，且不易立刻发现（无显式 NaN）。

**FP16 更容易**：可表示最大值约 65504，且梯度更小更易被吃掉。

---

## 6. Loss scaling（混合精度训练）

**思路**：前向算 loss 后乘大因子 S，反传梯度整体放大 S 倍，使许多小梯度 **进入 FP16 可表示区间**；优化器步长再除以 S（或等效处理），数学上等价于原问题。

**动态 loss scaling**：监测 inf/NaN，自动升降 S，兼顾范围与稳定。

---

## 7. 梯度爆炸 vs 「数值爆炸」

- **梯度爆炸**：深度/循环结构、过大学习率、损失地形陡 → **梯度范数变大**，可能仍是有限浮点数，但更新失控。
- **数值爆炸**：logits、exp、除法等产生 **inf/NaN**，属于表示范围或不稳定算法问题。

二者相关但不等价：可先数值稳定（scaling、clip、算子精度），再谈梯度裁剪与架构。

---

## 小结

- Adam 的「矩」是 **可微的在线统计**；bias correction 解决 **冷启动偏小**。
- AdamW 解决的是 **正则与自适应步长的耦合** 问题，不是换了个名字。
- BF16/FP16 选择是 **动态范围 vs 精度** 的权衡；master weights + loss scaling 是混合精度训练的标准认知。
