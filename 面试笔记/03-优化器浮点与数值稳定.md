# 03｜Adam / AdamW、浮点格式与数值稳定

**建议阅读顺序（本篇内部）**：先搞清 **Adam 在累加什么统计量** → **为什么要 bias correction** → **AdamW 和 Adam 差在哪** → 再谈 **FP16/BF32 混合精度里各张量用什么 dtype** → **溢出/下溢** → **loss scaling** → **梯度裁剪与 Adam 是否重复** → 最后区分 **梯度爆炸 vs 数值炸 inf**。

对应题库：Adam、混合精度、BF16/FP16、溢出等。

---

## 1. Adam：一阶矩、二阶矩在估什么

对每个参数（口述时可「独立近似」）：

- **一阶矩 m**：梯度 **指数滑动平均**，像「平滑后的梯度方向」。  
- **二阶矩 v**：梯度 **逐元素平方** 的滑动平均，像「这维梯度历史上通常有多大」。

更新直觉：`Δθ ∝ - lr · m / (sqrt(v) + eps)`。  
**梯度噪声大、历史幅度大的维** → 分母大 → **步长自动变小**；长期同向的维 → 分子大 → **加速**。这就是「自适应学习率」口语来源。

常用更新式（面试可直接写）：

```
m_t = β1 m_{t-1} + (1-β1) g_t
v_t = β2 v_{t-1} + (1-β2) g_t^2
m̂_t = m_t / (1-β1^t),   v̂_t = v_t / (1-β2^t)
θ_{t+1} = θ_t - lr * m̂_t / (sqrt(v̂_t) + ε)
```

符号别混：

- `g_t`：第 `t` 步当前参数的梯度（`∂L/∂θ`），与 `θ` **同形状张量**，不是单个标量。  
- `β1, β2`：EMA 的记忆系数（0~1 之间）。越接近 1 越“记历史”、更平滑但反应更慢；越小越“看当前”、抖动更大。  
- **EMA 本质**：`新值 = β * 旧值 + (1-β) * 当前观测`。Adam 里一阶矩对 `g_t` 做 EMA，二阶矩对 `g_t^2` 做 EMA。

### 面试怎么答

「Adam 用梯度一阶矩当方向、二阶矩当每个坐标的学习率缩放器。」

---

## 2. bias correction（偏差修正）为什么非做不可

初始化 `m=0,v=0`。前几步真实梯度已经进来，但 EMA 仍被 0 **往下拽**，**系统性偏小** → 早期更新过怂。

用 `m_hat = m/(1-β1^t)` 等在 **t 小**时放大，`t` 大后因子→1。这是 **有限步 EMA 的偏差**，不是装饰。

### 面试怎么答

「冷启动时动量估计偏小，除以 1-β^t 把早期步长拉正常。」

---

## 3. Adam vs AdamW：别只记名字

先把名词对齐：

- **L2 正则（加在 loss 上）**：`L_total = L_task + (λ/2)||θ||²`。  
对参数的梯度会多一项：`∂L_total/∂θ = g + λθ`。  
- **Weight Decay（更新时衰减权重）**：不改 loss，直接在更新里乘一个收缩：`θ <- (1 - lr*wd)θ + ...`。  
它起源于经典 SGD 时代对参数范数做约束（抑制权重无界变大、减轻过拟合）的工程实现；在 **纯 SGD** 下它与 L2 常可视作等价（系数映射后）。

**痛点（Adam 里）**：若把 L2 的 `λθ` 混进梯度，再走 Adam 的 `/(sqrt(v)+eps)`，这项也会被按坐标缩放。你以为是统一衰减，实际不同坐标衰减不同，和「理想的 weight decay」不一致。

具体看一个二维例子（只看正则项，方便看“扭曲”）：

- 设 `θ=[1,1]`，`lr=1`，`λ=0.1`，且某步 `sqrt(v)=[1,100]`。  
- 若把 L2 混进 Adam 梯度，正则导致的更新近似为  
`Δθ_L2 = - lr * (λθ)/(sqrt(v)+eps) = [-0.1, -0.001]`。  
同样是 `θ=1`，两维衰减差 **100 倍**，这就是“被 `v` 按坐标扭曲”。  
- AdamW 的 decoupled decay 是 `Δθ_wd = -lr*wd*θ`，若 `wd=0.1` 则两维都是 `-0.1`，这才是统一 shrink。

**AdamW**：**解耦 weight decay**——先按 Adam 用梯度走一步，再对权重做 **与梯度无关** 的 shrink（或等价写法）。**正则强度** 和 **自适应步长** 可分开调。

```
θ_{t+1} = θ_t - lr * m̂_t/(sqrt(v̂_t)+ε) - lr * wd * θ_t
```

等价写法：

```
θ_{t+1} = (1 - lr*wd) * θ_t - lr * m̂_t/(sqrt(v̂_t)+ε)
```

### 面试怎么答

「AdamW = Adam + 解耦权重衰减；大模型默认用它是为了正则不被自适应分母搞乱。」

## 4. FP32 / FP16 / BF16：先记「指数位=动态范围，尾数位=精度」

- **FP32**：8 位指数 + 23 位尾数，基准。  
- **FP16**：5 位指数 + 10 位尾数 → **动态范围窄**，大 logits 易 **上溢**，小梯度易 **下溢**；尾数短 → **舍入粗**。  
- **BF16**：8 位指数 + 7 位尾数 → **指数同 FP32**，**数量级上更像 FP32**，通常更「稳」；尾数更短 → **细精度不如 FP32**。

**为何 FP16/BF16 训练里，优化器常保留 FP32（主权重 + 状态）**：

1. **小更新会被半精度吃掉**：例如参数约 `1.0`，某步真实更新量可能是 `1e-6 ~ 1e-5`。FP16 在该量级的可分辨步长更粗，`θ - Δθ` 可能回写后仍等于原值；FP32 主权重可把这些小步 **累加起来**，再 cast 回半精度做前向。
2. **Adam 的 `m,v` 需要更稳定累计**：`v` 是平方梯度的 EMA，既可能很小也可能跨数量级；若用 FP16 存，容易下溢成 0 或舍入噪声放大，导致 `m/sqrt(v)` 比例失真。
3. **数值安全边界更大**：FP32 的指数范围与尾数精度都更宽，能减少「状态抖动、更新断档、偶发 NaN」。

**实践口径**：计算常用 FP16/BF16（省显存、提吞吐），但 **优化器更新链路** 常保留 FP32：`master weights` + `m/v` +（很多实现里）梯度累加/通信也用 FP32。

### 面试怎么答

「BF16 宽指数像 FP32，训练不易炸尺度；FP16 省但更爱配合 loss scaling；主权重 FP32 防更新被吃掉。」

---

## 5. 上溢与下溢；FP16 为何更敏感

- **上溢**：中间结果超范围 → inf/NaN，反传直接坏。  
- **下溢**：非零被当成 0 → **看似在训、其实没梯度**，难查。

FP16 最大约 6e4 量级记忆即可，**比 BF16/FP32 窄很多**。

---

## 6. Loss scaling（混合精度）

**动机**：反传梯度太小，FP16 **表示不了**，等价于 0。

**做法**：把 loss 乘 **S** 放大梯度，优化器里再 **除回 S**（或等价），数学不变。

`S` 是什么、从哪来：

- **静态 loss scaling**：`S` 是人设超参（常取 2 的幂，比如 `2^12 ~ 2^16` 区间按任务试）。  
- **动态 loss scaling（工程更常见）**：框架自动维护 `S`。典型逻辑是：  
  1. 用当前 `S` 放大 loss 反传；  
  2. 若发现梯度出现 `inf/NaN`，这步跳过 `optimizer.step()` 并把 `S` 降低（常减半）；  
  3. 若连续若干步稳定无溢出，再把 `S` 提高（常翻倍）。  
  本质是在「尽量大（防下溢）」与「不能大到溢出」之间找平衡点。

### 面试怎么答

「FP16 梯度容易 underflow，先把 loss 放大让梯度进可表示区间，再缩回优化步。」

---

## 7. 梯度裁剪（clip）和 Adam 的关系

**clip 在干什么**：限制 **全局或逐层梯度范数** 的上界，使 `optimizer.step()` 前更新步不会离谱大。**不改变**「loss 设计」，是 **优化动力学补丁**。

**和 Adam 是否重复**：Adam 的自适应分母 **按坐标缩放**，**不保证**全局范数小；大 loss spike 时仍可能 **单步飞走**。大语言模型训练里 **global norm clip（如 1.0）** 很常见，与 **BF16/FP16** 混用不矛盾。

### 面试怎么答

「clip 控全局更新幅度；Adam 管每坐标尺度；两者叠加大模型里很常见。」

---

## 8. 梯度爆炸 vs 数值爆炸（inf）

- **梯度爆炸**：范数大、更新猛，但仍是有限数；靠 **clip、调 lr、改结构** 等。  
- **数值爆炸**：已经 **inf/NaN**，先查 **溢出、不稳定 softmax、除零** 等。

二者相关但不等价：先数值稳定，再谈 clip。

---

## 本篇小结

- Adam = **动量 + 按坐标缩放步长 + 偏差修正**。  
- AdamW = **正则不要和自适应搅在一起**。  
- 浮点 = **动态范围 vs 精度** 的权衡；混合精度 = **算 FP16/BF16 + 存 FP32 权重 + 可能 loss scale**。  
- **梯度裁剪** = **全局步长保险丝**，与自适应不重复。
