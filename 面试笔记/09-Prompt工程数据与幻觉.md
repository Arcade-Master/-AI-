# 09｜Prompt 工程、数据清洗、Instruction 构造、幻觉

对应：**面试题2** 第 18、36～38 节（偏产品与数据管线）。

---

## 1. Prompt engineering：不是「玄学咒语」

**目标**：在 **不改模型权重** 的前提下，通过输入格式与上下文组织， **缩小模型解空间**、 **对齐输出格式**、 **注入约束与角色**。

**如何判断 prompt 是否达标**

- **任务成功率**：同一 prompt 多次采样 **pass@k**、或确定性设置下 **一次通过**；
- **约束满足**：格式（JSON）、长度、禁止项；
- **鲁棒性**：换表述、换语序、中英混写仍稳。

**如何评估 prompt**

- 离线：**小集标注 + 规则校验**（schema、单元测试）；
- 线上：**影子流量**、人工抽检、badcase 回放；
- 版本化：prompt **git 管理**、与模型版本 **绑定发布**。

---

## 2. Few-shot vs CoT vs Role prompt

| 类型 | 作用机制 | 典型风险 |
|------|----------|----------|
| **Few-shot** | 用示例 **锚定输出分布**（风格、格式、任务边界） | 示例噪声会被模仿；token 成本 |
| **CoT** | 显式要求 **分步推理**，扩大有效计算深度 | 过程胡编仍可能自信；更长输出 |
| **Role** | 软约束 **语气与立场** | 与系统安全策略冲突时需系统层兜底 |

**为何影响稳定性**：prompt 改变 **条件分布**；温度>0 时同一 prompt 亦随机——稳定性要 **prompt + 解码参数 + 后处理** 一起看。

## 3. 数据清洗与 instruction 构造（工程向）

**常见清洗**

- **去重**（MinHash/LSH）、**去 PII**、**语言检测**、**低质过滤**（乱码、广告、模板站）；
- **毒性/隐私** 过滤与 **合规** 审计；
- **长文本切分** 与 **文档结构** 保留（标题、列表）。

**脏数据处理**

- 规则 + 小模型 **质检** + 人工 **spot check**；
- 记录 **清洗版本号**，保证 **可复现**。

**Instruction 数据构造**

- 人工写、**模型合成 + 人审**、**工具执行链** 生成；
- 覆盖 **指令类型**（抽取、改写、推理、工具调用）与 **难度谱**；
- 与 **系统提示**、**工具 schema** 对齐，避免训练-服务 **格式漂移**。

---

## 4. Hallucination：如何发现与缓解

**定义**：模型生成 **看似合理但与事实不符或无依据** 的内容。

**发现**

- **检索对照**（RAG 评测）、**可执行验证**（代码运行、计算器）、**人审**、**一致性检查**（多次采样矛盾检测）。

**缓解**

- **RAG** 提供可引用证据；**约束解码**；**拒绝回答策略**；**RLHF/DPO** 降低胡编语气；**工具调用** 把事实交给外部系统。

---

## 5. 面试常问「实际项目」：怎么答才像做过

**做过哪些数据清洗**

- 按 **来源** 说：网页 / 书籍 / 对话 / 代码各一套规则；**去重、去 PII、语言与质量过滤、长度分桶**；用 **版本化脚本 + 抽样质检表** 证明可复现。

**如何处理脏数据**

- **规则优先**（正则、黑名单域名）、**模型打辅助标签**、**难例进人审队列**；明确 **丢弃 vs 修正** 的阈值，避免「全洗成同一种安全废话」导致分布塌缩。

**如何构造 instruction 数据**

- **意图覆盖矩阵**（任务类型 × 难度 × 语言）；**正负例对**（好回答 / 拒答 / 澄清）；与线上一致的 **system + tools schema**；合成数据必须 **人审或强模型交叉审**。

**如何发现 hallucination**

- 离线：**与知识库/检索结果对照**、**可执行检查**、多采样 **自洽性**；线上：**用户点踩、引用缺失检测、低置信触发拒答或检索**。

---

## 小结

- Prompt 是 **条件化生成** 的工程接口；评估要 **任务 + 鲁棒 + 成本**。
- 数据是 **模型行为的上界**；清洗与版本管理与写架构同等重要。
- 幻觉是 **概率生成 + 训练目标不惩罚编造** 的结构性问题，靠 **系统与数据** 缓解而非一句「别瞎说」。
