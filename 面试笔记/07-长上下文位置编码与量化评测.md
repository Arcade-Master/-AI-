# 07｜位置编码、长上下文扩展、量化、评测

对应：**面试题2** 第 5 节（位置编码、RoPE）、第 33 节（长上下文）、第 34 节（量化）、第 35 节（评测）。

---

## 1. 为什么 Transformer 需要位置编码？

Self-attention 本身是 **集合操作**：置换 token 顺序若不改 QKV，则 **输出在置换下几乎同构**——模型 **默认不知序**。

位置编码把 **序信息** 注入 token 表示；可以是绝对、相对、或旋转（RoPE）。

---

## 2. RoPE（Rotary Position Embedding）在干什么？

**核心**：把 Q、K 按维度对 **二维旋转**，旋转角随 **相对位置 m-n** 变化，使得 attention 内积 **自然只依赖相对距离**。

**为何适合长文本（相对优势）**

- 归纳偏置是 **相对位置**，与「远近关系」更一致；
- 与 **线性 attention 扩展**、长度外推研究结合多。

**外推为何会「失效」**

- 训练见到的位置区间有限，旋转频率组合在 **更长位置** 上可能产生 **训练未见的干涉模式**；
- softmax attention 的 **注意力分散/尖锐度** 随长度变化；
- 实际系统还有 **上下文窗口截断、KV 精度** 等工程因素。

**常见缓解（知道名字 + 作用）**

- **Position interpolation（PI）**：把位置索引 **缩放到训练窗口内**，牺牲「绝对位置精细度」换稳定。
- **NTK-aware scaling**：调整基频 / 带宽，使 **高频/低频** 分量的外推行为更温和（经验修正多）。
- **YaRN**：结合插值与注意力温度等技巧，针对 **极长上下文** 调优（细节以论文为准）。

面试答法：**外推 = 分布偏移**；缓解 = **重新标定位置尺度 + 调注意力锐度 + 继续训练/微调**。

---

## 3. 模型量化：INT8 / INT4 在做什么？

**目标**：用更少 bit 表示 **权重或激活**，减显存、提吞吐；代价是 **数值误差 → 掉点**。

**INT8 动态/静态**：缩放因子（per-tensor / per-channel）把 float 映射到 [-128,127]；矩阵乘可用 int8 GEMM。

**INT4（W4A16 常见）**：权重 4bit，激活仍 FP16/BF16；**权重大幅压缩**，对 **outlier 权重** 敏感。

---

## 4. GPTQ / AWQ / SmoothQuant（对比维度）

| 方法 | 侧重点 |
|------|--------|
| **GPTQ** | 逐层/逐列 **Hessian-aware** 贪心量化与误差补偿，偏 **权重量化** 后处理 |
| **AWQ** | 识别 **salient 权重**（对激活敏感），保护重要通道，强调 **激活感知** |
| **SmoothQuant** | 把激活的 **难度（outlier）迁移到权重** 侧，使 **整型矩阵乘** 更可行，偏 **W8A8** 训练/部署协同 |

**为何会掉点**：量化是 **有损压缩**；大模型里少数维度 **动态范围极大**；attention softmax 等对误差敏感。

---

## 5. 评测：perplexity、benchmark 与真实效果

**Perplexity（PPL）**：语言模型在 hold-out 文本上的 **平均负对数似然** 的指数；越低越好。反映 **建模分布能力**，不直接等于 **助手有用性**。

**Benchmark 与体感差异**

- 数据 **污染 / 过拟合**；
- 任务形态与 **用户真实 query** 不同；
- **长度、工具、多模态** 未覆盖。

**如何设计评测集**

- 分层：**知识 / 推理 / 指令遵循 / 安全 / 长文**；
- 动态更新、保留 **私有 held-out**；
- 线上 **A/B + 人类抽检** 与离线互补。

---

## 小结

- 位置编码解决 **置换不变性**；RoPE 提供 **相对几何** 视角。
- 长上下文 = **算法外推 + 系统 KV** 联合问题。
- 量化 = **表示压缩与 outlier 处理** 的生意；GPTQ/AWQ/SmoothQuant 是不同 **误差分配** 策略。
- 评测要会批评 **单一指标**。
