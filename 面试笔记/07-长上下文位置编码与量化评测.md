# 07｜位置编码、长上下文外推、量化、评测

**建议阅读顺序（本篇内部）**：**为什么要有位置编码**（否则 Transformer 不知道序）→ **RoPE 在做什么** → **为何外推会坏、常见修法** → **量化在解决什么 trade-off** → **三种后训练量化路线对比** → **评测为何不能只看一个数**。

---

## 1. 为什么 Transformer 必须加位置信息

Self-attention 对 token 集合几乎是 **置换等变** 的：你不告诉它顺序，它就 **默认不知道谁先谁后**。位置编码（绝对、相对、旋转）就是把 **序** 编进向量里。

### 面试怎么答

「Attention 本身不辨序；位置编码提供序信息。」

---

## 2. RoPE：旋转位置嵌入在干什么

把 Q、K 的某些维度当成 **平面上的向量**，按 token 下标施加 **不同转角** 的旋转，使得 **内积只依赖相对距离 m-n** 这类归纳偏置——比「直接加一个位置向量」更自然地和注意力点积结构拧在一起。

**为何长文相关**：相对位置归纳 + 后续各种 **长度缩放** 研究多建立在 RoPE 上。

### 2.1 口述版「公式骨架」（不依赖 LaTeX）

把隐藏维 **按相邻两维一对** 看成复数平面上的复数（或 2×2 旋转块）。对位置 m 的向量乘上 **块对角旋转矩阵** `R(m)`，对位置 n 同理 `R(n)`。注意力里出现的是 **`R(m) q` 与 `R(n) k` 的内积**；利用旋转正交性，可整理成 **`q^T R(n-m) k`** 形——**只出现相对位移 `n-m`**，这就是「相对位置进点积」的骨架。

**频率**：不同维度对对应 **不同角速度**（波长从短到长）；**高频**对相邻 token 敏感，**低频**抓长距模式。外推坏，常是 **训练未见过的 m-n 组合** 让这些相位 **落在分布外**。

### 面试怎么答

「RoPE 用旋转让注意力分数自然带相对位置；长文外推是它的工程痛点之一。」

---

## 3. 外推为什么会「坏」、常见怎么救

**根因一句话**：训练只见过有限长度，**更长位置上的相位组合** 对模型是 **分布外**；再叠加 softmax **注意力形态变化**、KV 精度等工程因素。

**常见手段（记名 + 作用）**

- **位置插值（PI）**：把位置索引 **压回训练窗**，换稳定、牺牲细粒度绝对位置。  
- **NTK-aware scaling**：调频率/带宽，让高频/低频分量外推更温和（经验修正多）。  
- **YaRN**：插值 + 调注意力「温度」等组合，冲极长上下文（细节以论文为准）。

### 面试怎么答

「外推 = 超出训练分布；缓解是缩放位置索引 + 有时再微调 + 注意力锐度处理。」

---

## 4. 量化：为什么要量化、INT8/INT4 各动谁

### 4.1 要解决什么问题

大模型 **FP16/BF16 权重** 占显存大头（7B 量级就十几 GB）。**量化（quantization）** 用 **更少 bit** 存同一个张量的近似值，换：

- **推理显存下降**（权重从 16bit → 4bit 约 **4×** 压缩量级，还看是否只量权重）；  
- **吞吐可能上升**（若硬件有 INT4/INT8 GEMM 内核）；  
代价是 **数值误差** →  logits 漂移 → **困惑度上升或任务掉点**。

### 4.2 量的是权重还是激活

- **权重量化**：`W` 用 INT8/INT4 存，计算时 **反量化** 到 FP16 再算，或走整型 kernel。  
- **激活量化**：中间层 `A` 也量化 → 可进一步加速，但 **动态范围随输入变**，更难。  
- **W4A16（常见部署）**：**权重 INT4，激活仍 FP16/BF16**——实现相对稳，**注意力、LayerNorm** 仍吃 FP 带宽。

### 4.3 为何大模型难：outlier（离群值）

部分权重/激活通道存在 **极大值（outlier）**。若用 **统一 scale** 量化，outlier 会把大部分正常值 **挤进很少的量化 bin** → **有效精度崩**。所以很多方法在争：**保护哪些通道、如何把难量的部分挪走**（§5 三条路线）。

### 面试怎么答

「量化是用 bit 换显存/速度的有损压缩；LLM 难点是 outlier；W4A16 常只压权重，激活仍 FP。」

## 5. GPTQ / AWQ / SmoothQuant：三条后训练量化路线

前提：**模型已训好**，不做（或很少）全量重训，在 **校准集** 上估 scale，把 FP 权重压成低 bit。

### 5.1 GPTQ（权重量化，逐层贪心）

**思路**：按层把权重矩阵分块，用 **二阶信息（近似 Hessian）** 决定 **先量化哪一列、步长多大**，使 **量化误差对输出的影响** 尽量小。偏 **离线后处理**：给一层层 `W` 做 INT4/INT3。  
**特点**：实现成熟、**主要动权重**；对 **激活 outlier** 不直接解决（仍靠 W4A16）。  
**面试一句**：「GPTQ = 权重量化后处理，逐层贪心最小化重构误差。」

### 5.2 AWQ（Activation-aware Weight Quantization）

**观察**：并非所有权重同等重要——**放大后会导致激活很大的那些权重列** 更敏感。  
**做法**：在校准集上找 **对激活影响大的「显著权重」**，给它们 **更高精度或保护**（少压 bit / 单独 scale），其余正常量化。  
**特点**：**激活感知**，仍主要是 **权重量化**，但选 **保护谁** 的依据来自 **激活统计**。  
**面试一句**：「AWQ = 按激活敏感度保护重要权重，再压别的。」

### 5.3 SmoothQuant（为 W8A8 把难量的激活「挪」到权重）

**观察**：激活里 outlier 多、难直接 INT8；权重相对好量。  
**做法**：对某层做 **数学等价变换**（平滑）：把一部分 **激活尺度** 用 **权重吸收**（`Y = (X/s) · (sW)` 类思想），使 **激活动态范围变窄** 便于 INT8，同时 **权重略调**。目标是 **权重+激活都能 8bit** 的 **W8A8** 推理。  
**特点**：偏 **整网低比特推理栈**（如 TensorRT-LLM 一类路径），不是「只压权重就完事」。  
**面试一句**：「SmoothQuant = 平滑激活 outlier 到权重侧，好做 W8A8。」

### 5.4 对照（怎么选口径）

| | 主要压谁 | 核心 trick | 常见部署形态 |
|---|----------|------------|--------------|
| GPTQ | 权重 | 逐层 Hessian 贪心 | W4A16 |
| AWQ | 权重 | 保护激活敏感列 | W4A16 |
| SmoothQuant | 权重+激活 | 平滑迁移尺度 | W8A8 |

### 面试怎么答

「三条都是训后量化；GPTQ 贪心压权；AWQ 按激活挑重要权保护；SmoothQuant 为 W8A8 平滑激活。」

## 6. 评测：PPL、benchmark、线上各量什么

### 6.1 PPL（困惑度 Perplexity）

**定义**：在 **测试文本** 上，模型对每个 token 的 **负对数似然 NLL** 取平均，再 `exp`：

```
PPL = exp( mean_t( -log p(y_t | y_<t) ) )
```

**越低越好** → 表示 **「模型有多『惊讶』于这段真实文本」**。  
**局限**：PPL 量的是 **语言建模能力**，**不等于** Chat 助手 **有用、安全、会跟指令**；SFT/RLHF 后 PPL 与用户体验 **可脱节**。手撕时分母必须 **只对有效 token**（见 **`11` §7**）。

### 6.2 公开 benchmark

如 MMLU、GSM8K、HumanEval 等：**固定题型、固定答案** 的 **离线榜**。  
**问题**：训练数据 **污染**（测题进过预训练）、**刷榜过拟合**、题型 **与真实用户 query 分布不一致**。  
**用法**：看 **相对排名与趋势**，别当 **唯一 KPI**；重要任务要 **自建 held-out**（公司私有题、脱敏日志抽样）。

### 6.3 线上评测

**A/B**、人工抽检、**任务成功率**（工单解决率、代码 PR 合并率）、**安全拦截率**。  
**长文**：除榜外还要看 **needle 检索、多跳推理** 等 **专测**（与 `13` RAG、长窗结合）。

### 面试怎么答

「PPL 看建模；benchmark 易污染只能参考；上线看 A/B 与业务指标，重要能力自建私有集。」

- 位置 = **补序**；RoPE = **相对几何**；外推 = **分布偏移**。

- 评测 = **多维 + 线上**。
