## 1. 交叉熵：先讲故事，再认公式

### 1.1 前因后果

语言模型在做的事，可以粗暴理解成：**给下一个词一个概率分布**。训练时我们手里有「真实下一个词」（one-hot 或带平滑的标签），记真实分布 **p**，模型预测 **q**。我们希望 **q 在 p 非零的地方别太小**——否则「真实会发生的事」在模型眼里概率极低，说明模型离谱。

**交叉熵**就是把「离谱程度」变成一个可优化的数：在真实会发生的那些事件上，用 **-log q** 惩罚；对离散类别求和（或期望）：

```
H(p, q) = - Σ_x  p(x) · log( q(x) )
```

**为什么是 p·log(q)，不是 q·log(p)？**  
权重必须是 **p**：「世界按什么频率出题」由 **标签/数据** 决定；里面用 **log q** 看「模型在那些事上的自信」。若反过来用 q 当权重，等于让模型自己决定「哪些错误更重要」，和「用人类标注对齐」的目标不一致。

**为何不对称、KL 也不对称**：`H(p,q) ≠ H(q,p)`。KL `D_KL(p‖q)` 的含义是「用 q 去近似 p」多付的信息量；**p 和 q 交换角色，问题本身变了**，所以不对称是定义使然，不是实现写错。

**与 KL 的关系（记结论即可）**：固定 p 时，`H(p,q) = H(p) + D_KL(p‖q)`，其中 `H(p)` 与模型无关。故 **最小化交叉熵 ⇔ 最小化 KL(p‖q)**——分类里爱用 CE，信息论上就是在对齐分布。

### 1.2 面试怎么答（30～45 秒）

「交叉熵衡量模型分布 q 在真实分布 p 上的平均惊讶度；p 在外面当权重，所以是 p log q。不对称是因为 KL 本身是有向的『用谁近似谁』。训练里固定标签就固定了 p，最小化 CE 等价最小化 KL。」

## 2. MSE：什么时候用它

均方误差：对样本平均 `(y - ŷ)²`。梯度对 ŷ 正比于 `(ŷ-y)`，误差大时更新步子大。

**适用**：回归、噪声预测、重建等 **连续值**。分类输出若硬套 MSE，往往不如 CE，因为类别是 **离散事件**，用「欧氏距离在 logits 空间」并不对应「概率上的错」。

```
Logits 的数值差，不等于概率差的语义差。

因为概率是 softmax(logits) 得到的，softmax 有两个性质：

平移不变性：softmax(z) = softmax(z + c)
也就是你把所有 logits 同时加 10，概率完全不变。
但 logits 的欧氏距离变了很多。

非线性压缩：logits 差一点点，概率可能变化很大；
也可能 logits 差很大，但概率几乎不变（在饱和区）。

所以在 logits 上用 MSE（欧氏距离）去度量“错多少”，会出现几何错配：
logit 空间的“近”不代表概率分布“近”，logit 空间的“远”也不一定代表概率“远”。
```

### 面试怎么答

「MSE 给连续目标；分类用 CE 因为要对整个概率单纯形建模，CE 与最大似然一致。」

## 3. Sigmoid 与 Softmax：一对「压概率」的工具

- **Sigmoid**：把一个实数压到 (0,1)，**彼此独立**，适合二分类或门控。  
- **Softmax**：一组 logits 变成 **互斥**、和为 1 的概率，适合多分类。

**速记公式**：

```
Sigmoid（逐元素）:
σ(x) = 1 / (1 + e^{-x})

Softmax（对类别维 C）:
softmax(z)_i = e^{z_i} / Σ_{j=1..C} e^{z_j}

稳定写法（先减最大值 m=max(z)）:
softmax(z)_i = e^{z_i - m} / Σ_{j=1..C} e^{z_j - m}

log_softmax:
log_softmax(z)_i = z_i - log Σ_{j=1..C} e^{z_j}
```

**数值稳定**：softmax 整体加常数不变，故先减 `max` 再 `exp`，避免指数炸掉。和 CE 连用时工程上常用 **`log_softmax` + `nll_loss`**，避免 `log(softmax)` 丢精度。

**为什么会溢出/消失（高频追问）**：

- **Softmax 溢出风险**：若某个 logit 很大，`exp(z)` 会非常大，超出浮点可表示范围变 `inf`；分母求和再做除法就可能 `inf/inf -> NaN`。所以工程里几乎都用 `z - max(z)` 的稳定写法。
- **Sigmoid 梯度消失风险**：`σ'(x)=σ(x)(1-σ(x))`，当 `x` 很大或很小时，`σ(x)` 接近 1 或 0，导数接近 0；层层反传相乘后梯度会快速变小（深层更明显）。
- **二分类里 softmax 是 sigmoid 特例**：两类 logits 记为 `z1,z2`，则  
  `p(y=1)=exp(z1)/(exp(z1)+exp(z2)) = 1/(1+exp(-(z1-z2))) = σ(z1-z2)`。  
  即 softmax-2 类等价于对 **logit 差值** 做 sigmoid。

### 面试怎么答

「多分类用 softmax 得到分布再对真实类取负 log；实现上用 log_softmax 稳定。sigmoid 是逐元素，不保证和为 1。」

## 4. L1 与 L2

| | L1 | L2 |
|---|----|----|
| 惩罚 | λ·Σ\|w\| | λ·Σw² |
| 几何 | 菱形约束，易顶到坐标轴 → **稀疏** | 球形，**均匀缩小** |
| 口述 | 更像「关掉不重要的维」 | 更像「整体别太大」 |

大模型微调里 **weight decay** 常与 AdamW 同聊（见 03）。

### 面试怎么答

「L1 倾向稀疏解，L2 平滑收缩；深度网络正则更多见 L2/weight decay，L1 多见于压缩或特征选择场景。」

## 5. NumPy / Tensor 的 axis

**唯一可靠规则**：`axis=k` 表示 **沿第 k 维做归约，该维从结果里消失**。先 `print(shape)`，再选 axis。

例：`(batch, seq, hidden)` 对序列平均 → `axis=1`。

### 面试怎么答

「我不死记行和列，只看 shape：要消哪一维就 axis 哪一维。」

## 6. DFS 与 BFS

- **DFS（深度优先）**：栈/递归，空间跟 **递归深度** 走；适合回溯、拓扑、探索大空间配合剪枝。  
- **BFS（广度优先）**：队列，空间跟 **当前边界规模** 走；边权为 1 时求 **最少步数**、层序遍历。

### 面试怎么答

「最短路且无权用 BFS；要剪枝或写回溯用 DFS。」

## 7. 手撕参考代码

```python
import numpy as np
from collections import deque

def cross_entropy_from_probs(p, q, eps=1e-12):
    q = np.clip(q, eps, 1.0 - eps)
    return float(-np.mean(np.sum(p * np.log(q), axis=-1)))

def mse_loss(y_true, y_pred):
    return float(np.mean((y_pred - y_true) ** 2))

def stable_softmax(z, axis=-1):
    z = z - np.max(z, axis=axis, keepdims=True)
    e = np.exp(z)
    return e / np.sum(e, axis=axis, keepdims=True)

def sigmoid(x):
    return np.where(x >= 0, 1.0 / (1.0 + np.exp(-x)), np.exp(x) / (1.0 + np.exp(x)))

def dfs(adj, start):
    seen, st = set(), [start]
    order = []
    while st:
        u = st.pop()
        if u in seen:
            continue
        seen.add(u)
        order.append(u)
        for v in adj.get(u, ()):
            if v not in seen:
                st.append(v)
    return order

def bfs(adj, start):
    seen, q = set(), deque([start])
    order = []
    seen.add(start)
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj.get(u, ()):
            if v not in seen:
                seen.add(v)
                q.append(v)
    return order
```

## 8. 第 k 大元素（快速选择 / 小根堆）

**题意**：无序数组里找第 k 大（k 从 1 计），不必全排序。

**快速选择**：随机 pivot 做 partition，看排名落在左还是右，只递归一侧；平均 O(n)，最坏 O(n²)。

```python
import random

def find_kth_largest(nums, k):
    target = len(nums) - k  # 升序下标

    def partition(lo, hi):
        p = random.randint(lo, hi)
        nums[p], nums[hi] = nums[hi], nums[p]
        pivot = nums[hi]
        i = lo
        for j in range(lo, hi):
            if nums[j] <= pivot:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[hi] = nums[hi], nums[i]
        return i

    lo, hi = 0, len(nums) - 1
    while True:
        m = partition(lo, hi)
        if m == target:
            return nums[m]
        lo, hi = (m + 1, hi) if m < target else (lo, m - 1)
```

**小根堆**：维护大小为 k 的最小堆，堆顶即第 k 大；适合 k 小或流式，O(n log k)。

### 面试怎么答

「第 k 大 = 升序里下标 n-k；快排 partition 减治；或 k 小时用大小为 k 的小根堆。」

## 9. Label smoothing：为什么要在 one-hot 外「抹一点概率」

**动机**：硬标签 `p = one-hot` 时，模型被鼓励把 **非真类概率压到机器零** → **过自信、泛化差、校准差**（logits 极大）。

**做法**：把真类从 1 改成 `1-ε`，其余类平分 **ε/(K-1)**，再对该 **软 p** 算交叉熵（或等价改 CE 目标）。**效果**：梯度不再无限推高真类 logit，**类间 margin 更平滑**。

**代价**：有意引入 **bias**（不再严格 MLE）；**ε** 常很小（如 0.1 量级，依任务扫）。

### 面试怎么答

「Label smoothing 把硬 one-hot 变软，防过拟合 logits 爆炸、改善校准；ε 要 dev 调。」

## 10. Focal loss（分类里类不均衡时提一句）

在 CE 前乘 **`(1 - p_t)^γ`**，`p_t` 为模型对真类的概率。**直觉**：**易样本**（`p_t` 大）权重趋 0，**难样本**权重大 → 训练注意力集中在 **难分例**。检测里常见；LM 主损失较少用，但 **「降易例权重」** 叙事可迁移到 **hard example mining** 讨论。

---

## 本篇小结

- CE/KL：**有向、用 p 加权**，不是对称「距离」娱乐题。  
- softmax/sigmoid：**互斥 vs 独立**，稳定实现靠 **减 max / log_softmax**。  
- axis：**看 shape 消维**。  
- k 大：**partition 或堆**。  
- Label smoothing / focal：**校准与难易样本权重** 两个独立旋钮。
