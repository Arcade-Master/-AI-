## 1. 交叉熵：从「编码成本」理解，而不是背公式

**一句话**：交叉熵回答的是——若真实世界按分布 p 发生事件，你却用「为 q 设计的编码」去传消息，平均要多付多少比特（或 nat）的代价。

**离散形式**（对类别 x 求和）：

```
H(p, q) = - Σ_x  p(x) · log( q(x) )
```

**为什么是 p·log(q)，不是 q·log(p)？**

- 抽样与权重的语义：训练数据里「哪些 x 会出现」由 **真实/标签分布 p** 决定（one-hot 或平滑标签）。你要惩罚的是：在这些 **实际会出现** 的 x 上，模型给的 q(x) 有多离谱。因此 **p 必须在外面当权重**。
- 若用 q·log(p)：等价于按「模型认为重要的区域」加权；但那些区域未必是标注关心的区域，优化目标与「拟合人类标注」错位。
- **不对称**：H(p,q) 与 H(q,p) 一般不等。KL 同理：D_KL(p‖q) 度量的是「用 q 近似 p」的额外代价，交换 p、q 后含义变成「用 p 近似 q」，数值与梯度结构都不同——这不是 bug，是 **有向** 信息距离。

**与 KL 的关系**（理解即可，不必死记符号）：

```
D_KL(p ‖ q) = Σ p · log(p/q) = ( -Σ p·log(q) ) - ( -Σ p·log(p) ) = H(p,q) - H(p)
```

p 固定时 H(p) 常数，所以 **最小化交叉熵 = 最小化 KL(p‖q)**。这也解释为何分类里交叉熵是「标准答案」：它在信息论里对应最优编码长度差。

**实现要点**：工程上几乎总用 **logits + log_softmax + nll_loss**（或 fused CE），避免先 softmax 再 log 造成精度损失；手撕面试可用 numpy 版先算稳定 softmax 再套 CE。

## 2. MSE：何时用、梯度含义

**定义**：对样本求平均的 `(y - ŷ)²`。

- **适用**：回归、扩散里噪声预测、部分重建任务。分类末端若强行用 MSE，往往不如 CE，因为 **概率单纯形上的几何** 与「平方距离」不一致。
- **梯度**：对 ŷ 的导数正比于 `(ŷ - y)`，误差大时步长大；若配合过大学习率易振荡，这是调参时要心里有数的原因。

## 3. Sigmoid 与 Softmax：分工与数值稳定

**Sigmoid**：把单个实数压到 (0,1)，独立门控 / 二分类 logits 常用。

**Softmax**：把一组 logits 变成 **和为 1 的互斥概率**，多分类输出层常用。

**减 max 技巧**：softmax 对整体加常数不变，故先 `z = z - max(z)` 再 exp，避免 exp 上溢；下溢只会使某些项为 0，一般可接受。

**和交叉熵组合**：用 `log_softmax` 比 `log(softmax)` 更稳，这是「公式一样、实现不同」的典型考点。

## 4. L1 与 L2：几何与统计两种视角

| | L1 | L2 |
|---|----|----|
| 惩罚 | λ·Σ|w| | λ·Σw² |
| 几何 | 约束域角点在轴上 → 稀疏 | 球约束 → 均匀收缩 |
| 统计 | 拉普拉斯先验倾向 | 高斯先验倾向 |

**面试怎么说清「为什么 L1 稀疏」**：在坐标轴附近，L1 的「等势线」是菱形；最优解更容易顶在角上 → 某些维为 0。L2 是光滑凸球，交点常在面上 → 很少严格 0。

**实践**：大模型里 weight decay 常与 AdamW 搭配（见 03 篇）；L1 在大规模稀疏化里更多见于特定压缩管线，不是 SFT 默认项。

## 5. NumPy / Tensor 的 axis：用 shape 想，别用「行列表」硬背

**规则**：`axis=k` 表示 **沿着第 k 维做归约，该维在结果中消失**。

- 二维 ` (batch, dim) `：`axis=0` 得到长度为 dim 的向量（对 batch 聚合）；`axis=1` 得到长度为 batch 的向量。
- 三维 ` (batch, seq, hidden) `：对序列做 mean 常 `axis=1`，保留 batch 与 hidden。

手写 attention mask 时，务必打印 `tensor.shape` 再选 axis，避免 silent bug。

## 6. DFS 与 BFS：能力边界

**DFS**：栈或递归；空间 O(深度)；适合拓扑序、强连通、回溯组合。

**BFS**：队列；空间 O( frontier )；**无权图最短路**、层序遍历。

**对比记忆**：同一道题若问「最少步数」且边权为 1，优先想 BFS；若状态空间爆炸且要剪枝，常 DFS + 回溯。

## 手撕参考代码（面试默写级）

```python
import numpy as np

def cross_entropy_from_probs(p, q, eps=1e-12):
    q = np.clip(q, eps, 1.0 - eps)
    return float(-np.mean(np.sum(p * np.log(q), axis=-1)))

def mse_loss(y_true, y_pred):
    return float(np.mean((y_pred - y_true) ** 2))

def stable_softmax(z, axis=-1):
    z = z - np.max(z, axis=axis, keepdims=True)
    e = np.exp(z)
    return e / np.sum(e, axis=axis, keepdims=True)

def sigmoid(x):
    return np.where(x >= 0, 1.0 / (1.0 + np.exp(-x)), np.exp(x) / (1.0 + np.exp(x)))

from collections import deque

def dfs(adj, start):
    seen, st = set(), [start]
    order = []
    while st:
        u = st.pop()
        if u in seen:
            continue
        seen.add(u)
        order.append(u)
        for v in adj.get(u, ()):
            if v not in seen:
                st.append(v)
    return order

def bfs(adj, start):
    seen, q = set(), deque([start])
    order = []
    seen.add(start)
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj.get(u, ()):
            if v not in seen:
                seen.add(v)
                q.append(v)
    return order
```

## 7. 手撕：第 k 大元素（快速选择 / 堆）

**题意**：在无序数组里找 **第 k 大**（k 从 1 开始），不要求完全排序。

### 思路一：快速选择（平均 O(n)，最坏 O(n²)）

用快排 partition：随机或取中轴 pivot，一趟把 **大于 pivot** 放左边、小的放右边；看第 k 大落在哪一侧，只递归一侧。

```python
import random

def find_kth_largest(nums, k):
    """1-based：第 1 大即最大值"""
    target = len(nums) - k  # 升序里下标：第 k 大 = 升序倒数第 k 个

    def partition(lo, hi):
        p = random.randint(lo, hi)
        nums[p], nums[hi] = nums[hi], nums[p]
        pivot = nums[hi]
        i = lo
        for j in range(lo, hi):
            if nums[j] <= pivot:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[hi] = nums[hi], nums[i]
        return i

    lo, hi = 0, len(nums) - 1
    while True:
        m = partition(lo, hi)
        if m == target:
            return nums[m]
        if m < target:
            lo = m + 1
        else:
            hi = m - 1
```

**说明**：上面 partition 按「小于等于 pivot 在左」组织，故 `m == target` 时 `nums[m]` 是升序第 `target` 小，即第 k 大。

### 思路二：最小堆（时间 O(n log k)，适合流式 / k 较小）

维护大小为 k 的 **小根堆**，堆顶为当前 k 个里最小的 → 全局第 k 大。

## 小结

- 交叉熵 / KL 的「不对称」来自 **有向** 的近似与抽样权重，不是实现细节。
- Softmax、sigmoid 的考点一半是 **数值稳定**，一半是 **和损失函数的衔接**。
- axis、DFS/BFS 属于 **基本功**：能说清复杂度与适用场景即可在工程题里串联到 DataLoader、图算法、搜索等话题。
- 第 k 大：能说清 **partition 减治** 与 **堆** 两种即可。
