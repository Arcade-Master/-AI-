# 12｜策略梯度、GAE、PPO、GRPO、Value（计算向）

**建议阅读顺序（本篇内部）**：**REINFORCE / Value / GAE** → **PPO clip** → **GRPO 组内基线** → **GSPO 序列级 ratio** → **DAPO / VAPO 变体** → **REINFORCE++**。  
与 **`05`** 分工：`05` 讲 **管线选型与面试总括**；本篇讲 **公式与一步训练循环**。

---

## 1. REINFORCE：梯度里为什么出现 log π

**目标**：最大化期望回报 `J(θ) = E_{τ~π_θ}[ R(τ) ]`（`R` 可为整条轨迹回报或折扣和）。

**对参数 θ 的梯度**在 log-trick 下写成 **轨迹上采样估计**：

```
∇_θ J ≈ E[ Σ_t ∇_θ log π_θ(a_t | s_t) · G_t ]
```

`G_t` 常取 **从 t 开始的回报**（蒙特卡洛回报）。**问题**：`G_t` **方差极大**，同样动作好坏波动大 → 更新抖、样本效率低。

**baseline（减基线）**：用 `G_t - b(s_t)` 代替 `G_t`；若 `b` 与动作无关，**期望梯度不变**、方差常降。最常令 **`b(s) ≈ V^π(s)`**（状态价值：从 s 出发按当前策略走的期望回报）。

### 面试怎么答

「REINFORCE 是无偏蒙特卡洛策略梯度，乘 logπ 梯度；减 value baseline 降噪不降期望。」

---

## 2. Value `V(s)` 与 Advantage `A(s,a)`

- **`V(s)`**：固定策略 π 下，从状态 s 开始的 **期望回报**（要对动作序列取期望）。  
- **用途**：定义 **优势** `A(s,a) = Q(s,a) - V(s)`，直觉是 **「这个动作比该状态下平均好多少」**。把 raw return 换成优势后，策略梯度估计 **方差更小**。

**Critic**：一个网络 `V_φ(s)` 用回归去拟合 **bootstrap / MC 目标**；PPO 里 critic 与 actor **同轨迹更新**。

### 面试怎么答

「Value 估状态平均回报；优势把『绝对好坏』改成『相对平均的好坏』。」

---

## 3. GAE：从 TD 误差叠出多步优势（PPO 前几乎必接）

记 **一步 TD 误差**（实践中用 value 估计）：

```
δ_t = r_t + γ V(s_{t+1}) - V(s_t)
```

**GAE(λ)** 定义优势为指数加权：

```
A_t = Σ_{l=0}^{∞} (γλ)^l · δ_{t+l}
```

- **`λ=0`**：`A_t ≈ δ_t`，**低方差、有偏**（只看一步）。  
- **`λ→1`**：接近 **长程 MC 优势**，**方差大、更无偏**。  
- **工程上**：`λ` 在 **0.9～0.98** 一带扫；和 **`γ`（折扣）** 一起决定 **信用分配多远**。

### 面试怎么答

「GAE 用 TD 残差 δ 的指数和造优势；λ 调偏差-方差折中。」

---

## 4. PPO：clip 目标 + KL/熵（能默写结构即可）

**比率**：`r_t(θ) = π_θ(a_t|s_t) / π_{θ_old}(a_t|s_t)`（旧策略采样、新策略评估 **同一批动作**）。

**裁剪 surrogate（单条轨迹期望近似）**：

```
L^CLIP(θ) = E_t[ min( r_t(θ)·A_t , clip(r_t(θ), 1-ε, 1+ε)·A_t ) ]
```

- **`A_t > 0`**（好动作）：不希望 `r_t` 爆大 → **clip 上限** 防止一步把概率推太狠。  
- **`A_t < 0`**（坏动作）：不希望 `r_t` 趋近 0 时仍猛压 → **clip 下限** 防止过度惩罚。  
- **`min(...)`**：取 **悲观（更保守）** 那一支，形成 **信任域近似**。

**总目标常还加**：**价值函数 loss**（MSE 到 return/GAE 目标）、**熵 bonus**（防过早塌缩成确定性策略）、**KL(π_θ ‖ π_ref)** 或 early-stop on KL（对齐阶段锚 SFT）。

**一步 PPO 循环（口述用）**：`π_old` 采样 → 算 `V`、`A`（GAE）→ 对同一 batch **多 epoch 小步更新** `θ`，但每次仍用 **旧 logprob 固定** 算 `r_t`（实现里存 `log π_old`）。

### 面试怎么答

「PPO = 旧策略采样 + GAE 优势 + clip 比率限制更新幅度 + critic + 熵/KL。」

---

## 5. GRPO：组采样、组内基线、目标长什么样

**设定**：固定 prompt `x`（或状态里已含 prompt），当前策略 **`π_θ` 独立采样 G 条**完整回答 `{y_i}_{i=1..G}`。

**标量回报**：每条得 `R_i`（单元测试、数学检查、RM、格式分等）。定义 **组均值** `μ = (1/G) Σ R_i`，常用 **标准差** `σ` 做归一化。

**组内优势**（最常见口述式）：

```
A_i = (R_i - μ) / (σ + eps)   或   A_i = R_i - μ
```

**策略梯度项**：对每条 `y_i`，令 `L_i = Σ_t log π_θ(y_{i,t} | x, y_{i,<t})`（整条序列 log-prob 和），上升：

```
+ α · A_i · L_i   （最大化期望）
```

实现里常写 **最小化 `-A_i·L_i`**，并 **对 i 求平均**。**KL 到参考** 仍常加：` - β KL(π_θ ‖ π_ref)`，防止为刷 `R` 生成不可读文本。

**和 PPO 的差别（面试必讲）**：

| | PPO | GRPO |
|---|-----|------|
| 优势来源 | **时序** GAE + critic | **同 prompt 多样本** 互相当基线 |
| 是否需要 `V(s)` | 通常要 | **弱化或不要** |
| 采样结构 | 单轨迹多步 credit | **同条件 G 条完整输出** |
| 适用奖励 | 任意 dense/sparse | **可重复判分**（代码、数学）最香 |

**方差直觉**：绝对分 `R_i` 会随任务整体难度漂移；**减组均值**后更像「这批里谁更好」，**可比性**强。

### 面试怎么答

「GRPO 对同一 prompt 采 G 条，用组内中心化回报当优势，乘整条 log π；省 critic、吃可验证奖励；KL 仍常锚参考。」

## 7. GSPO：序列级 importance ratio（长序列方差）

**设定**：与 GRPO 相同——对 prompt `x` 采 **G 条**完整回答 `y_i`，得标量奖励 `R_i`，组内 baseline 得优势 `A_i`（如 `A_i = (R_i - μ_G) / (σ_G + ε)`）。

**GRPO/PPO 在长序列上的问题**：token 级 importance  
`r_{i,t}(θ) = π_θ(y_{i,t}|·) / π_{θ_old}(y_{i,t}|·)`  
在 **|y_i| 很大** 时，各 token 比率 **独立波动、相乘进目标**，梯度估计 **方差随长度恶化**。

**GSPO 的核心**：定义 **序列级** 比率（几何平均，等价于平均 log-ratio）：

```
s_i(θ) = ( π_θ(y_i|x) / π_{θ_old}(y_i|x) )^{1/|y_i|}
       = exp( (1/|y_i|) Σ_t log [ π_θ(y_{i,t}|·) / π_{θ_old}(y_{i,t}|·) ] )
```

在 **序列粒度** 做 clip 与策略梯度加权（实现细节依仓库，面试抓 **「从 token 收到 sequence」** 即可）。直觉：**一条回答一个 trust-region 步长**，长链不会被成百上千个 token-ratio **放大噪声**。

**Group Size G 与收敛（与 GRPO 共用）**：

- **μ_G、σ_G** 用 **G 条样本** 估得越稳，**优势噪声越小**；G↑ 常 **加快稳定收敛**，代价是 **G 倍 rollout**。  
- 若 G 条 **奖励全相同**，中心化后 **A_i≈0**，该 prompt **几乎无梯度**——训练实现里常 **丢弃该组**（与 DAPO dynamic sampling 同思路）。

**相对 DPO**：DPO **不采样 rollout**，优化 **离线偏好对** 的 log-ratio；GSPO **在线 RL**，优化 **可验证奖励下的策略**，并针对 **长生成** 改 **importance 粒度**。二者 **问题设定不同**，不要答「GSPO 是 DPO 的改进版」。

### 面试怎么答

「GSPO 保留 GRPO 的组采样与组内 baseline，把 PPO/GRPO 的 token 级 importance 收到序列级几何平均比率，降低长回答 RL 的方差；G 越大 baseline 越稳但越贵。」

## 8. GRPO 变体：DAPO、VAPO（相对 GRPO 改在哪）

### DAPO（在 GRPO 上叠工程增强）

常见组件（名称因实现略有出入）：

1. **Asymmetric clip（Clip-Higher）**：`clip(r, 1-ε_low, 1+ε_high)` 且 **ε_low < ε_high**，允许 **适度放大** 好轨迹概率，又限制坏轨迹。  
2. **Dynamic sampling**：仅训练 **组内奖励有方差** 的 prompt；**全对/全错** 的组 **不浪费 backward**。  
3. **Token-level loss 归一化 / 过长惩罚**：缓解 **长短回答混 batch** 时梯度尺度不均。

相对 **朴素 GRPO**：**有效梯度密度更高、训练更稳**；超参更多（ε_low/ε_high、采样阈值等）。

### VAPO（value-augmented，与「去 critic」的 GRPO 对照）

**GRPO 路线**：用 **组内均值** 代替 `V(s)`。  
**VAPO 路线**：认为 **复杂推理** 仍需要 **靠谱的价值估计**，通过：

- **Value pretraining**（先让 `V` 像样）  
- **Decoupled-GAE / Length-Adaptive GAE**（长短序列混在一起时 **优势不偏**）  
- 仍可结合 **group sampling、clip-higher、token-level PG** 等

相对 GRPO：**多训一个 value 网络，换更低方差、有时更快达到高 reward**；工程更重。

| | GRPO | DAPO | GSPO | VAPO |
|---|------|------|------|------|
| Critic | 通常无 | 通常无 | 通常无 | **有，且重点优化** |
| 组采样 G | 核心 | 核心 + **过滤无效组** | 核心 | 可有 |
| Importance | 常 token 级 | 常 token 级 + 非对称 clip | **序列级** | token/序列依实现 |
| 典型场景 | 可验证奖励推理 | 大规模 RL 提效 | **长 CoT / 长推理** | 高难度推理 benchmark |

---

## 本篇小结

- 策略梯度 = **`∇logπ · 回报`**；baseline = **方差控制**。  
- GAE = **`δ_t` 的 γλ 加权和**。  
- PPO = **`min(rA, clip(r)A)` + critic + 熵/KL**。  
- GRPO = **G 样本组内基线 + 序列 logπ 加权**。  
- **GSPO** = **序列级** `s_i(θ)` 降 **长链 token-ratio 方差**。  
- **DAPO / VAPO** = GRPO 上的 **采样-clip** 与 **value** 两条增强路线。
